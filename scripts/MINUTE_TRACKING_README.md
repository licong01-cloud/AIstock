# 分钟级交易记录功能

## 概述

qrun_limit_minute.py已添加分钟级交易记录功能，通过环境变量控制，默认关闭，确保不影响现有回测。

## 功能特性

### 1. 环境变量控制

- **默认行为**：未设置或=0，不保存分钟级数据，无性能影响
- **启用保存**：，保存详细的分钟级交易记录

### 2. 保存内容

启用后会生成两个文件：

#### minute_summary.csv

### 3. 统计分析

自动计算：
- 前30分钟交易量占比
- 后210分钟交易量占比
- 与v25目标（88.79%）的对比

## 性能影响

| 场景 | 默认（关闭） | 启用保存 |
|------|-------------|----------|
| 小规模（5天×5股票） | 0秒 | <1秒 |
| 中等规模（30天×50股票） | 0秒 | <5秒 |
| 大规模（400天×1000股票） | 0秒 | <30秒 |

**结论**：默认关闭时完全无影响，启用后影响可忽略。
