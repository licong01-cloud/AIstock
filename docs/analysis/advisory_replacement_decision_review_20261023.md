## 3. 净替换标签与集合目标

对一个包的同一D，令原Top10为A、候选Top10为S、每股完整已知的固定5TD净估值为r_i，K=10。原生评价为：

```text
U(S) = (1/K) Σ_{i∈S} r_i
U(S) - U(A) = (1/K) [Σ_{j∈S\A} r_j - Σ_{i∈A\S} r_i]
单次替换 Δ(i→j) = (r_j-r_i)/K
```

多个替换的总价值与换入/换出如何配对无关。在相同D信息集I、共同估值定义及期望存在的条件下，`E[r_j-r_i|I]=E[r_j|I]−E[r_i|I]`。这不要求股票收益相互独立；相关性影响估计方差和风险，但不改变该均值恒等式。减去固定原生U(A)也不改变最大化U(S)的最优集合。

所以`g(i,j)=s_j−s_i`仍是一个可分个股打分器。允许所有可评分候选自由交换且沿用稳定tie/UNKNOWN槽规则时，最大化总预测替换收益仍然选择相同的分数TopK；用成对名义描述它没有新增持仓动作或反事实干预。

适用限制必须保留：

- 这里是固定推荐集合的离线估值，不是持仓延续、订单、真实换手、NAV或“卖掉i再买j”的交易反事实。
- 每股r已含原买0.95/sell5.95bps各一次；不能因称为替换而再扣一次买卖费用。个股既有费用不会产生新的股票对交互成本。
- 原生不可执行入场保留CASH=0；UNKNOWN/未成熟不填0、不删除后重算分母。组估值未定义时不能引用完整组收益恒等式补造结果。
- 预测中输入UNKNOWN固定原槽；训练只用成熟可测监督，不能用T/H状态筛选D时的配对或原候选。若只选历史完整配对，需重新说明共同支持/选择偏差，不能声称组合收益天然完整。
- 同一r被重复组成400个边不产生400个独立经济样本；跨包同股、共同D和5TD重叠仍相关。未增加独立确认窗口。

## 4. 平方损失：严格等价的条件与不等价的部分

令一个训练组有n个已知样本，`e_i=s_i−r_i`。完整无序配对平方损失满足：

```text
Σ_{i<j} [(s_j-s_i)-(r_j-r_i)]²
  = Σ_{i<j} (e_j-e_i)²
  = n Σ_i (e_i-mean(e))²
```

若`s_i=wᵀx_i+b`，右侧即中心化X/y的线性回归残差平方和乘n；截距抵消。每组配对和除以该组n，并保持相同训练人口、编码、缺失、日期权重和正则项，才与原中心化目标等价。固定n时也可同步缩放正则；有向双配对额外有2倍尺度。若n随日期或成熟样本变化而不归一化，则改变日期权重；从旧唯一stockD并集改成package/date也会改变重复权重。未证明这种不同实现会复现旧预测，更没有拿旧经济结果代替新结果。

只取原Top10组A（a=10）与其余40组B（b=40）的配对，则是二部图损失：

```text
L_AB = Σ_{i∈A,j∈B}(e_j-e_i)²
     = b Σ_A(e_i-mean_A)²
       + a Σ_B(e_j-mean_B)²
       + ab(mean_B-mean_A)²
```

它通常不是中心化损失的统一倍数。合成残差分别只在A内部、B内部以及两组均值之间变化时，`L_AB / 全组中心化SSE`分别为40、10、50；这直接反驳“任何pairwise都完全等价”。线性差分头的模型类仍然相同，但有限样本估计可能改变。

该区别不足以自动成为本轮实验依据：原生rank1..10对rank11..50的所有边不等于当前模型最终TopK边界的决策错误；纯边界平方损失仍惩罚幅度误差，未直接计算错误入选造成的净损失。选择这组权重需要可审查的学习假设，而不能用“直接净替换”名称把它当已实现的决策目标。本轮没有按历史收益选权重、截断排名或扫门槛。

## 5. 其它形式的真实区别与未评估项

| 形式 | 判定 | 本轮处理 |
|---|---|---|
| 旧分数作差，或条件相同且规范化后的完整线性配对平方损失 | 评分/学习目标重复 | 不进入F1 |
| 仅10×40边界配对平方损失 | 权重实质不同，可能影响估计；未证明有收益，也未证明无效 | 当前提案依据不足，不以调整权重救旧候选 |
| `P(r_j>r_i)`分类 | 新损失但胜率不等于期望净收益 | 合成例：90%赚1、10%亏20，胜率90%而期望−1.1；不能直接替代产品终点 |
| 独立股票对交互模型 | 模型类可能不同，不应声称与旧Ridge等价 | 相同完整信息集下真实期望差应可加；自由边预测可能环路不一致，需要额外聚合/冲突合同，当前未定义 |
| 限制最多替换次数、设置最小增益或不确定性门槛 | 动作/决策规则真实变化 | 可形成另一个研究问题，但不是无成本的同义改写；本轮不选档位、不恢复旧拒买/阈值搜索 |
| Listwise决策regret或SPO+ | 可与平方误差实质不同，本轮未证明等价 | 未评估/未启动；不能把本文的配对恒等式推广为决策学习无效 |

[Elmachtoub/Grigas原论文](https://arxiv.org/abs/1710.08005v5)以预测所诱发的决策误差为目标，并提出SPO+替代损失；它提供方法动机，而不是本项目两包、5TD、费用和输入下的收益证据。本轮的“净差标签”并没有自动实现这种训练目标。允许未来有明确假设的目标/模型研究，不要求每项研究都必须新增数据字段；也不据有限检索声称本仓所有相关方法均已覆盖。
