## 原因及证据边界

原21150行输入只有一行VSTD5极值：002856.SZ，D=2026-04-29，约6.046782670561247e18。对应停牌记录S、成交量0；公式`Std(volume, 5)/(volume+1e-12)`可产生巨大但有限的值，原NaN/Inf检查不会拒绝。

后续固定版本`20260831-qe_hmm_full_v2-direct-20260928-r8-unified-moneyflow1-candidate`的daily_pv.h5物理SHA256为`f53de996a3afd5477d0bb8967ed18eebdfa8e9d6724d03ea15a75d81056d4832`，与发布清单一致。其五个成交量5460100、6004000、15853600、11248300、0复算标准差6046782.670561263，除以1e-12可重现缓存，差异相对量2.71e−15。缓存指向的20260905原H5路径现已不存在，因此这证明可复现机制，不冒称原H5逐字节复原或历史PIT成立。

父包预处理资产SHA256 `c2d15f3cb1e7949ec2b87020359a145bafd85789675efd22458c7a8749ff2ed8`保存了`RobustZScoreNorm/clip_outlier=True`，但此前独立重排序实验明确使用自身训练中位数/IQR及缺失位，并未消费父包预处理统计量。原公式与实验编码均按各自已冻结合同执行；本任务不修改公式、剪裁阈值或缺失合同。

原线性推理先对特征做D日均值中心化，再做线性评分和分数中心化。巨大输入把正常49只股票的分数平移到约−1e19，此时binary64相邻值间距1024，普通股票数百量级的区别消失。原两臂各仅剩2种float分数，假同分最终按父rank排序，当日Top10退回原生Top10。

新增`scripts/advisory_lstm_linear_rank_replay.py`，默认`run`即执行校正回放。固定读取上一轮同一LSTM包、三折matched/candidate共六个JSON模型，先验证全部旧阶段链、源hash、原代码闭包和6 STARTED/6 FINISHED，再消费原输入与上下文。旧冻结v1入口保持只读，用于重现历史结果；不把历史资产静默改写为校正结果。
