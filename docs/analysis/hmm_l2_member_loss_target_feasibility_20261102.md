## 1. 问题与结果

现有模型预测行业组合十日末损失，而消费者实际买入部分成员股。要核验的是：行业组合内赢家与输家的抵消，是否丢掉了与成员亏损有关的信息。固定同一批成员、权重、价格及期限后，组合损失B与成员损失C的差异可以直接计算；不能将标签差异当成模型效果。

| 同一96,972个可比较行业—日期 | 平均损失 | 同日排序对照 |
|---|---:|---|
| A：原C-010逐日行业路径 | 2.044706% | A/B日均Spearman=0.976918 |
| B：固定as-of成员及权重的组合 | 2.147011% | B/C日均Spearman=0.808689 |
| C：同成员个股负收益的加权均值 | 2.951133% | C/成员上行收益日均Spearman=−0.560509 |

B与C完全共用成员、权重、期限和原生价格，平均抵消量`C−B=0.804122`个百分点。39,655行B为0而C大于0；706个单成员样本中B=C。两条恒等式在全部样本成立：`组合收益=上行部分−C`、`C−B=min(C,上行部分)`，最大复算误差小于8e-17。

这说明C保留了组合未亏损时的成员亏损分布，**不说明C更容易学习、风险排序已经改善或应减少该行业仓位**。同行业成员仍共享一个行业级预测，不能消除行业内个股差异。

## 4. 决策、设计和停止位置

建议一个新成员损失候选C，配一个同成员/权重/训练样本的组合损失B控制。保持20D、季度窗口、10D、Ridge参数；旧A模型原样只读。B/C在相同样本重拟合才有助于区分聚合目标效应，故详细设计建议两个vintage×两种目标×双fresh-process=8 fits；这是新设计预算，**本轮实际0 fit**，不冒称旧4-fit预算已经覆盖。

取舍以能否更好识别实际候选股票亏损为主，MSE仅作数值诊断；同时披露上涨机会，不能把风险直接变成禁买、仓位或排名公式。完整定义见[成员损失详细设计](../architecture/hmm_evolution_phase2_l2_member_loss_detailed_design_20261102.md)。设计不是新模型已实施或已通过效果验收，既有125日继续是已消费开发历史。
