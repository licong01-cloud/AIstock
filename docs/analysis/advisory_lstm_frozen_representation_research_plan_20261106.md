## 2. 为什么选这个假设，以及已经核实到哪里

冻结`model.py`实际定义单层LSTM，`hidden_size=64`、`batch_first=True`，前向路径为`lstm_out[:, -1, :] → Dropout(0.2) → Linear(64,1)`。在eval模式，取最后时间步的64维向量并经过原输出层，可与同输入的父预测分数核对。PyTorch明确提供序列输出及最终隐藏状态；这只支持提取方式，不能证明投资收益。[官方LSTM接口](https://docs.pytorch.org/docs/2.15/generated/torch.nn.LSTM.html)

待证伪假设`FROZEN_LSTM_STATE_FIXED5_V1`：冻结网络保留的序列状态，可能包含单一父分数和当前54字段未充分表达的排序信息。只训练一个小型下游5TD读取头；父网络权重、原输出层和父任务均不改变。64维状态是既有数据的变换，不是新增外部信息；有效维度、非冗余和收益都未证明。它也不等于更好的LSTM父模型或全市场Alpha。
