## 背景与方法

多 Alpha 路线的核心瓶颈是：6 个候选信号域因子零重叠，但**预测/选股是否真正独立从未实测**。
"因子零重叠 ≠ 预测独立"——FundVal 可能与 IF18 在选股上高度同向。在拿到相关矩阵之前，
"5-Alpha 组合 Sharpe>2.8" 只是 √(Σσ²) 的理论上界。

**现实约束（本轮发现）：** QE 数仓不存逐日预测分数（`priority_score_count=0`），
但每个 run 存了 `enhanced_metrics.all_stocks`（持仓全集 + profit_pct + holding_days）
与 `stock_trades`（逐股逐笔交易）。因此正交性用**实证代理**衡量：
- **持仓重叠 Jaccard** = |A∩B| / |A∪B|（两个 Alpha 选的是不是同一批股票）
- **持仓 Overlap 系数** = |A∩B| / min(|A|,|B|)（小集合被覆盖程度）
- **共同持仓 PnL Spearman 相关**（共同股票上，盈亏是否同向 → 选股质量是否同向）

不占任何 GPU/CPU，纯数仓 MCP + 本地计算。

## 核心结论

1. **5 个信号域两两都独立** —— 多 Alpha 路线首次拿到实证支撑。Jaccard ≤0.26、PnL相关 ≤0.40，全部低于独立阈值。
2. **C_FundVal 是最佳正交锚**：与所有域 Jaccard 0.13-0.22、PnL 0.19-0.32 全场最低，且本身 CV 2.7%/ICIR 0.81 最稳。此前担心"基本面估值 vs 机构资金流冗余"被证伪（C↔IF18 PnL 仅 0.192）。
3. **轻度相关对（仍可共存）：** a1↔a3（PnL 0.404，技术/基本面动量同向）、a2↔A_Flow（Jaccard 0.258，资金流双子域）。均 <0.5，无需合并，但组合权重上对二者降权。
4. **平均非对角 PnL 相关仅 0.249** → 分散增益巨大。

## 组合权重与 Sharpe 估计

单腿种子均值统计 + 两种加权方案：

| 域 | Sharpe | CV | ICIR | n | w(Sharpe/CV) | w(风险平价) |
|---|---|---|---|---|---|---|
| a1_PLUS3 | 2.45 | 11.0% | 0.71 | 30 | 21.3% | 25.3% |
| a2_IF18 | 2.01 | 5.0% | 0.62 | 8 | 20.2% | 18.2% |
| a3_FM12 | 2.15 | 24.3% | 0.74 | 3 | 14.4% | 15.0% |
| C_FundVal | 2.20 | 2.7% | 0.81 | 5 | 23.6% | 22.4% |
| A_Flow | 2.06 | 5.4% | 0.58 | 5 | 20.5% | 19.1% |

**组合 Sharpe 代理（用单腿 Sharpe + PnL 相关矩阵估算）：**
- 等权 ≈ 3.44
- Sharpe/CV 加权 ≈ 3.45
- 风险平价 ≈ 3.46

→ 三种方案差异极小（因相关已很低），**均远超单腿 SOTA 2.45 和此前 2.8 目标**。
推荐 **风险平价权重**（a1 25%/C 22%/IF18 18%/A_Flow 19%/FM12 15%），把权重略偏向最稳的 a1+C。

> 注：3.4+ 是"假设各腿独立运行后等比例混合预测/持仓"的上界估计，未计入真实多 Alpha
> 组合回测的执行摩擦、容量冲突、权重再平衡换手。真实值会低于此，但相关 0.25 的分散空间是真实的。

## 对下一轮实验的指令

1. **正交性已确认 → 不必再盲目找新信号域。** 重心转向"补齐样本 + 真实多 Alpha 组合回测"。
2. **α3_FM12 是最大短板**：n 仅 3、CV 24%。下一轮 GPU 首要补到 n=5（seed{42,2024,12345} 各 +1）。
3. **α5 MARG10 仍值得一测**（融资融券情绪，唯一未进正交矩阵的真新域），但**降级**：MARG10×LSTM+LGBM_C 各 3seed 探针即可，先看 CAGR 是否 >0.65、再看与现有 5 域的正交性。
4. **VOL12 按既定降级 3seed 探针**（B_TurnMom 已预判偏弱）。
5. **缺口仍在工程侧**：multi_alpha 架构代码的"真实 5-Alpha 组合回测"从未跑通——这是把 3.4 的理论上界变成可部署数字的唯一途径，优先级高于再扩信号。

## 复现

代表 run 产物可经 `qe_experiment_get(detail=full)` 重新拉取（5 个 experiment_id 见上表）。
脚本：从 `experiment.result_metrics.enhanced_metrics.all_stocks` 取 {code: profit_pct}，
按 code 对齐算 Jaccard / Overlap / Spearman。numpy 2.3.3 / scipy 1.16.3。

## 残余风险

- 正交性用"已实现持仓/PnL"作代理，而非"原始预测分数互相关"——若数仓未来补上 priority_score，应以预测分数复核。
- 各域代表 run 仅取单 seed，持仓集合受 seed 抖动影响；结论稳健性依赖各域已验证的种子鲁棒性（C/IF18/Flow CV 低，α3 CV 高需注意）。
- Sharpe 上界为静态混合估计，非真实组合回测结果。
