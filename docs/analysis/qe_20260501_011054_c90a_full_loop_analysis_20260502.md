## 2. 最重要结论

这个实验的最高优先级结论不是“某个模型一定优于另一个模型”，而是：**前 18 个 no-alpha loop 配置为 5D/10D/20D，但实际训练 label 全部是 1D；因此前 18 个 loop 的 5D/10D/20D 横向比较失效，也不能直接用于判断 no-alpha 是否弱于 alpha。**

```text
Scope        Loops        Config Alpha158  Config Horizon  Actual Horizon  Valid For Horizon Compare
-----------  -----------  ---------------  --------------  --------------  -------------------------
No-alpha     1-18         OFF              5/10/20         1D              No
Alpha        19-28        ON               5/10/20         5/10/20         Yes
```

代码级原因与 `qe_20260501_201036_b699` 相同：`disable_alpha158=True` 时使用 `DynamicFactorsOnlyLoader`，而旧 workspace 中 `qe_custom_loaders.py` 把 label 写死为：

```text
Ref($close, -2) / Ref($close, -1) - 1
```

这等价于 1D label。详细根因文档见：

```text
docs/analysis/qe_20260501_201036_b699_no_alpha_label_horizon_root_cause_20260502.md
```

## 7. Alpha158 的作用分析

### 7.1 实验内能确认的事实

Loop19-28 启用了 Alpha158。run.log 明确显示：

```text
Runtime Features = 20 Alpha158 + 57 custom = 77
```

但是 enhanced metrics 的 feature importance 只抽取了 57 个 custom factor：

```text
Feature Importance Scope = partial_57_of_77
```

因此，本实验不能直接给出 Alpha158 20 个基线因子的 gain 排名，也不能基于 feature importance 删除或保留某个 Alpha158 因子。

### 7.2 实验内不能直接证明的内容

不能直接证明：

```text
Claim                                      Reason
-----------------------------------------  ----------------------------------------------------
Alpha158 全量加入一定更好                  no-alpha 对照实际训练成 1D，不是同 horizon 对照
某个 Alpha158 因子贡献最高                 feature_importance 没覆盖 Alpha158 20 个基线因子
no-alpha 在 10D/20D 必然弱于 alpha         当前 no-alpha 10D/20D 实际训练目标是 1D
```

可以合理推断：

```text
Inference                                  Evidence
-----------------------------------------  ----------------------------------------------------
Alpha-enabled 10D/20D 序列模型值得继续     Loop19-28 actual horizon 正确，收益/Sharpe显著高
Alpha158 可能增强中周期序列模型            有效 alpha loop 的稳定性和收益显著强，但缺少严格 no-alpha 对照
后续必须重跑 no-alpha 正确 horizon matrix  否则无法定性 Alpha158 的边际贡献
```

- 如果没有 restore best，则当前结果可能仍有提升空间，优先修复 checkpoint 使用逻辑。

```text
P0        重跑 alpha: 同模型同 horizon 的 ON/OFF 严格对照         判断 Alpha158 边际贡献
P1        LSTM10D alpha 小网格                                    hidden=32/64/96, dropout=0.1/0.2/0.3, lr=3e-4/1e-3
P1        TCN10D alpha 小网格                                     channels=32/64/96, kernel=3/5, dilation层数, dropout
P1        GRU20D alpha 小网格                                     hs64/96/128, 10D vs 20D, dropout/weight_decay
P1        检查 PTNN checkpoint 是否使用 best epoch                 避免 final loss 恶化导致潜在性能损失
P2        Alpha158 top-only                                       只保留有效 Alpha158，避免全量噪声
P2        Multi-alpha: LSTM10D + GRU20D + Cat/XGB10D               组合中周期趋势和横截面排序
P2        V25尾部成交/现金优化                                    在不显著增大回撤前提下降低 10%-13% 期末现金
```

## 13. 架构师结论

这个实验最有价值的部分是 Loop19-28 的 alpha-enabled 序列模型矩阵。它显示当前 57 个自定义因子 + Alpha158 基线特征在 10D/20D 序列模型上有显著收益潜力，尤其是：

```text
Best Direction     Representative Loop  Why
-----------------  -------------------  ------------------------------------------------
LSTM 10D alpha     Loop26               当前收益/Sharpe/回撤综合最优
TCN 10D alpha      Loop24               收益强，作为 LSTM 的结构替代和集成候选
GRU 20D alpha      Loop19/22            RankIC最高、排序最稳定、适合慢变量趋势 alpha
Cat/XGB 10D alpha  Loop25/27            IC强，适合作为横截面子 alpha，不宜单独作为第一主线
```

但该任务不能直接回答“Alpha158 是否应该加入”这个问题，因为 no-alpha 对照组实际训练成了 1D。后续必须先修复 loader，再重跑严格矩阵。否则继续基于前 18 个 no-alpha loop 做结论，会把 label bug 当成模型差异或因子差异，导致错误优化方向。

最终建议：

```text
Decision Area        Recommendation
-------------------  ----------------------------------------------------------------
下一步第一优先级     修复 no-alpha label_horizon 并重跑严格 ON/OFF 矩阵
模型主线             LSTM10D alpha、TCN10D alpha、GRU20D alpha
模型非主线           LGB/XGB/CAT 暂作为横截面补充，不作为最高优先级主线
Alpha158             不能全量定论；先补 importance 和严格消融，再做 top-only
持仓/资金             当前无严重持仓超限；资金利用可优化但不是 P0
训练系统             必须展示 best checkpoint、loss曲线、restore状态和训练资源信息
```
