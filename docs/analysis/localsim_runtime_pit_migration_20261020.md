## 迁移语义

训练来源 PIT 是资产出处；运行 PIT 是本次选择股票的业务政策。两者分别登记，不能改写训练历史。现有 manifest 的 legacy 分类不作为 LocalSIM 更换运行 PIT 的模型重训门禁。

只改变 canonical authority 指针、风险股票池绑定和与之关联的运行身份。冻结处理器、因子顺序、模型序列长度、seed/权重、选股参数、手续费与执行政策继续保持原值。新政策导致股票池、截面特征、排序和收益变化是独立运行结果，验收不要求与旧政策结果相同。

原 `runtime_profile_id/version/hash` 保留为手续费、HMM、执行及来源身份。新发布中的 `localsim_runtime_pit_policy_v1` 与完整 `selection_runtime_config` 独立登记实际生效政策及权威 lease，并进入发布和原生选股缓存身份。加载时先校验来源 profile 原摘要，再调用公共纯 PIT 转换重建期望投影；除 PIT 变化外必须逐项相等，禁止仅改名或放宽选股校验。未迁移发布继续使用原合同。

历史回放在首个尚无经济事实的日期创建同账户新政策接续段。旧任务的状态、游标、失败字段及完整已完成前缀全部保留；仅递增 CAS 版本以使提前采样的 worker 失效，并以原生前驱链接封存，在新绑定的审计回执保存完整前驱和批准快照。原绑定退休，调度器拒绝继续执行退休绑定。不能手改 FAILED_TERMINAL 或伪装 recover。已存在在途或经济副作用的未完成日禁止迁移。

日常账户在第一个尚未完成的交易日创建单日新政策后继发布，保留旧账本作用域。后续沿用现有逐日发布机制，每个新业务日调用公共 authority 冻结新 lease；已冻结回放段恢复时读取原 lease。权威覆盖可以在同一规则下延伸；规则或参数摘要改变必须再次显式迁移，不能静默切换。日常运行与回放共享源码、各自独立政策身份和计算状态。

## 实施与运行边界

操作工具默认只读计划；应用要求精确账户列表与既有计划回执的摘要，不是包 ID 白名单。`--in-process` 仅允许在新进程中只读预检；应用必须通过用户重启后实际加载的后端 API，不能绕过运行加载。后台 API 与操作工具调用同一个迁移服务。所有持久化在现有数据库事务内执行，不新增数据库、不修改数据集或市场数据。先在既有 DEV 数据库验证，再依据本轮明确迁移授权对生产目标执行。生产账户策略清单来自权威登记，不以示例包 ID 分支。

权威 generation、来源摘要、覆盖或账户/任务版本发生变化时重新计划，禁止静默套用旧计划。当前权威覆盖至 2026-10-19，日常 2026-10-20 的迁移必须等待合法覆盖；不能推算成员或绕过覆盖校验。
