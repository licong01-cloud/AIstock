# 荐股 PIT 输入范围与筹码缺失修复

日期：2026-10-30。BUG-2144，Issue #6906。沿用共享完整性权威和全局 PIT，不新增股票池或数据补齐流程。

## 问题与批准的语义

用户要求：已经不再属于 PIT 范围的股票不得阻断荐股；当前无法补齐的筹码源缺口按缺失处理。此前四包被整日分区完整性阻断，尽管 19 只股票的 272 个 bak_basic 缺失键已不属于决策日 PIT 成员。

原生推理实际以决策日 D 的全局 PIT 成员读取完整模型历史窗口。因此消费者范围是“D 日成员 × 正式模型窗口 × 包依赖数据源”。不能按历史事实日的成员资格删去已恢复入池股票需要的历史输入；不修改全局 PIT、Top50/Top10 人口、包资产或预处理。

共享设计中的全市场事实完整性继续独立保留。非 Advisory 消费者继续遵守原判定。本次仅对已经验收、修订一致、缺口键齐全且计数闭合的股票分区做消费者投影：

- 不在决策日实际成员内的缺口不阻断本次预测，仍保留在源台账。
- 消费范围内的 cyq_perf `MISSING` 以 NaN 原始输入消费，记录键、源验收摘要和策略版本；不伪称 source_complete、LEGAL_NA 或历史 PIT。
- 筹码 `INVALID`、实际需要的其他字段缺失，以及未验证、旧规则、计数不闭合、缺口截断、未知来源继续阻断。
- 稀疏目录、行业/指数聚合等不能按个股成员过滤。只支持明确证券键合同的数据源，来源别名按共享日期身份还原。

NaN 在冻结模型预处理前保持；冻结的训练预处理及现有不可评分处理不变。此修复不保证每个成员都可评分，不新增补零、前填、重拟合或额外股票剔除规则。

## 实现与一致性

`advisory_scope.py` 读取同一只读快照中的 D 日成员，绑定成员摘要、策略版本和缺口证据。`consumers.py/service.py` 仅为 ADVISORY 投影并返回质量计数。`inputs.py` 在捕获和发布前核对相同版本、PIT、成员摘要和缺口摘要；发布前独立重读成员并重新分类。分区 pin 保留验收元数据，避免 dense 分区失去 coverage_basis 后被误判待验。

`inference_engine.py` 在原始数据读取完成、冻结模型计算之前验证接受的筹码缺口仍是 NaN，缓存补值或遗漏对应行会明确失败。数据源修订、验收变化、PIT 变化及实际读取范围变化均使旧绑定失效。

第一轮自审检查 D 日成员和完整历史窗口，避免把按事实日过滤误当修复。第二轮检查来源别名、NaN 保留、捕获和发布一致性，补上分区验收元数据与数组参数规范化。第三轮按 DESIGN-COMPLIANCE-001 检查：无简化成功声明、无吞错或伪造完整、用户批准的缺失语义显式版本化、无额外人工审批或新模型资格门禁。以上为本窗口自审，不宣称独立外审。

新增定向测试 25 项已通过；最终相关矩阵 140 项通过，Ruff 和 L0 通过。PR CI 单独验收跨模块回归，结果在 BUG/PR 中登记。

## 当前残余与后续验收

当前全局 PIT 为 `aistock_equity_pit_canonical_v2`，D=2026-10-29 成员 4918 个。四包的新投影已处理上述 bak_basic 和筹码缺失；但 2026-10-27、10-28 的 cyq_perf，以及三个依赖 bak_basic 的包对应两天的 bak_basic，仍使用旧 provider scan 验收结果，缺少 `independent_dated_traded_stock_keys` 证明，故整体保持 WAITING。需要数据窗口按现有 validator 重新验证这四个分区，无需因此重复采集、补零或修改 PIT。本轮未修改生产台账。

旧多 alpha 父包仍按既有资产闭包判断，本修复不解除缺失训练资产阻断。用户重启后核对运行身份、四包 `input_scope/input_quality`、源台账残余及实际输入绑定，再区分源码修复、生产生效与新预测是否完成。
