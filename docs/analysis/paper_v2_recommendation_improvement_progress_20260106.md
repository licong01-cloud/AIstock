### 核心结论
1. **IC/RankIC 不应作为唯一指标**，需综合评分体系
2. **多 Seed 稳定性**（CV < 10%）比单次最优更重要
3. **Worst-case CAGR** 是荐股更合适的指标
4. **多策略包集成**能显著提升胜率（+10-20%）
5. **交易策略包 vs 荐股策略包应分开优化**，共享基础
