# 因子研究：用途驱动选题、完整评价与批量交接执行设计

日期：2026-10-22；状态：执行设计，研究尚未启动。

依据：[方法论 v2.12](factor_research_methodology.md)、[蓝图 v1.15](../architecture/factor_research_evolution_blueprint_20260908.md)。本文只承接下一轮执行，不复制或修改方法定义，不改变 P1/P2 历史验收事实。开发权威仍为项目开发标准；本轮是 docs-fast-new，不是新平台或共享引擎开发。

## 1. 目标与投入决定

目标是发现对约500万元至1亿元资金的板块轮动、持续领涨识别或趋势退出有价值的新因子/新表示，而非增加候选数量、统计指标或流程记录。资金范围不是已验证容量。

下一轮依次完成三个工作包：

1. **W1：选择一个确实未回答的问题。** 从已有成功/失败趋势研究、因子历史及实际 QE 输入中定位缺口；先核对经济假设、竞争解释和可识别性，再决定是否生成候选。不是重新扫描全部历史或再做一遍裁剪归因。
2. **W2：对形成的技术有效候选完成全 PIT、全有效历史、八期限独立评价和相关性，再按指定用途比较。** 先前已有等价完整结果直接复用，不重算凑任务。
3. **W3：按实际配方关系形成一批有理由的接收建议。** 有必要实验的问题交 QE；尚可由现有产物回答的问题由本窗口完成。批量是协调方式，不是数量门槛，也不是将所有候选一起塞进一个模型。

本轮设计不声称已找到新机制。当前没有足以直接批准实现的新公式；W1 是一个有边界的选择任务，而非允许无限研究后仍只交付流程。W1 结束必须决定具体问题、为何不同于已测规格、下一项最有信息量的动作；找不到则明确本轮不生成候选并结束，不自动搜窗口和翻方向。

## 3. W1：有边界的选题设计

### 3.1 首要问题与可证伪竞争解释

首要问题：**在相近的趋势、波动与交易活跃条件下，现有非价格输入是否提供此前研究尚未检验的、能区分延续与失败的观测？**

不是预设这些输入一定有效，也不直接把它们相乘。经济解释与竞争解释成对提出：

| 调查线索（不是批准实现的公式） | 潜在经济解释 | 首先排除什么 | 允许继续的不同依据 |
|---|---|---|---|
| 两融参与与趋势延续 | 有融资参与的需求可能延续，也可能因拥挤而脆弱 | 已测净偿还主效应、回撤/压力交互；覆盖仅限两融标的 | 历史明确显示一个尚未测试的观测关系，且不是换窗口、状态或方向；输入时点可验证 |
| 资金与成交活跃度之间的分歧 | 相同上涨路径可能来自不同交易需求 | ID1544及流量强度、价格尺度、档位重组、连续资金流已有结论 | 原研究未比较的经济问题及可分辨证据，不把订单档位当机构身份 |
| 同月历史表示的学习用途 | 长期日历价格摘要可能补充短期输入 | 正向季节性叙事、短有效训练历史、已测滚动OLS | 这是已评价备选的用途/接收问题，不算新的主线机制 |

前两项先查具体任务、公式及结论，不能仅凭表中宽泛措辞批准计算。两项均已被等价问题回答时，W1 到此结束；不把第三项升级为“新因子成功”，也不继续从数百字段自动筛最优。其他明显不同的新证据可写入后续建议，但不在本轮临时扩大搜索空间。

### 3.2 实际动作与产物

1. 用现有 `list/show/context/memory-search` 定位相关记录和源公式；仅查上述问题及直接关联任务，不扫描全部 RD-Agent 目录。不以关键词无结果证明没有研究过。
2. 对可能不同的观测，核对已有数据字段、单位、历史可得时点和覆盖；先读小型元数据及既有结果，不重新哈希数据目录、补数、导出或激活。
3. 按需要查一篇直接相关原论文/原研报，明确样本、期限、成本与反例。只有摘要时标为摘要；外部正结果不替代本地结果，未知发布时间不得假设 PIT 正确。
4. 形成简短“问题选择决定”：旧结论、实质区别、正反预期、原始观测、简单对照、原始方向或拟合方向、主要用途及会改变决定的下一项结果。没有实质区别则只记一句结束理由。

本工作包上限是完成上述两个线索的判断，不是凑两个新候选。若需要新的现象计算，先在现有研究库登记问题与尝试，再实施研究侧小脚本；本设计提交本身不写研究库。

### 3.3 现象研究的可比较口径

有不同依据时才计算；优先复用已有完整日频事件及其生成逻辑，不能把事后最高涨幅股票作为入样条件。

- 以当时 PIT 资格、当时已知数据定义母体；保留新进入、持续、退出强势状态及普通股票对照，不仅筛“今天还很强”的幸存者。
- 复用旧事件时保持其T−1状态定义；候选若使用T日收盘数据，最早按既有T+1入场合同评价。两融等源字段另遵守实际可得延迟，不能把数据日期等同可消费时刻。比较两者时明确各自信息集，不静默把旧事件改成T日状态。
- 固定已有 r20/r60、波动匹配口径作为可比参照，新增规模/活跃度控制若会改变问题必须事先说明，不在看到结果后挑最有利匹配。行业只作诊断控制，不承诺组合中性。
- 涉及两融时同时报告全 PIT 覆盖和两融可观察子集，不将不可观察者填零；不得把只覆盖子集的效果宣布为全市场可部署。
- 历史全有效区间用于探索；优先用2024年前的可得阶段形成假设，再按时间回放2024年至截止。已看过的历史继续标 `research_feedback`，不宣称重新切分恢复独立性，不等待未来行情才能工作。
- 成功/失败标签只用于事后评价，定义按已有收益标签和同日全资格截面，不从筛完的强势小样本重新选最高/最低组；中间样本保留并报告。
- 一个观测只回答预先说明的问题；无条件、条件、缺失子集分别报告。重复股票日、重叠收益不作独立样本。局部概率差不是净收益，也不是完整因子结论。

W1 的正面现象仅使“值得实现一个固定候选”合理；负面结果结束该调查问题，不能给未实现的全市场因子贴无效标签。已经实现并技术有效的候选必须进入 W2，不能借 W1 局部诊断逃避完整评价。

## 4. W2：候选实现及完整评价

### 4.1 实现前固定的最小合同

沿用研究卡/context_json，不新建表或必填审批系统。明确问题、公式、输入与单位、发布时间/延迟、形成窗口、股票观测时钟或交易日历、缺失语义、方向来源、主要用途、对照、探索/评价范围、已看结果以及不同结论对应的决定。

具体公式应由 W1 的证据决定，不能在设计中假称已选择；实现前写明公式后审查，再登记计算。默认只推进最有依据的一项，不设候选配额；另一项若已被旧结果回答立即跳过。

候选计算只用历史可得输入；禁止跨股票 rolling、未来回填、负 shift 引入未来、把停牌/未上市/缺字段混作零。异常值及空值原因可解释，不通过删除低覆盖股票缩小分母。未知财务可得时点的候选维持未验证，不借日线估值代理伪装公告更新。

### 4.2 数据与时间

- 新研究由现有入口解析执行时全局 active profile，记录任务级绑定；不硬编码 v15/v18，不另造版本选择或目录身份系统。恢复同一尝试沿用原绑定，不因 active 更新混算。
- 旧产物只在实际数据、代码、值与样本合同相容时复用；不能证明可比则标出差异，不能把历史快照叫当前 active。引用既有 manifest 身份，不全量重算哈希。
- 全历史独立评价从已发布数据允许的最早信号日到任务截止；暖机与首次有效日期单列。优先分析2024年以来、2026年及最近月份，但不是只看三个月。
- 预测期限为1/5/10/20/40/60/120/240日。依据共享上下文返回的期限映射、`label_calendar`、`horizon_support`独立判断成熟；标签两端实际可得，不从期限名字直接做日期减法。长周期未成熟不裁掉短周期。
- 比较按逐年历史拟合/评价回放，方向与选项只在相应拟合信息内确定；边界排除未成熟和跨界标签。历史反馈与真正未接触验证分开，不要求新增未来数据。

### 4.3 复用现有实现，不扩建引擎

2026-10-22源码核对的复用入口：

| 功能 | 现有实现/合同 | 本轮做什么 |
|---|---|---|
| 记录/恢复/经验 | `scripts/factor_research.py`，现有 tasks/records | 执行前核对所需子命令帮助；提交失败 attach，不重算 |
| 多期限上下文 | `qe_eval_v2_metric_engine.prepare_shared_context(..., holding_periods=[1,5,10,20,40,60,120,240])` | 研究请求显式八期限，不改官方默认四周期 |
| 全期及分期指标 | `full_evaluation.build_standard_windows`、`compute_candidate_metrics` | 当前已含全部有效年份、2024以来、最近6/3/1月及2024后逐月；后者传 `include_horizon_metrics=True` |
| 候选对存量 | `full_evaluation.compute_correlation_views` | 复用参照值，候选×参照分批及候选间计算；不重算存量×存量全矩阵；不要求逐月重复全相关 |
| 角色比较 | `comparison.validate_comparison_spec`、`compute_comparison` | 复用 `predictive_increment/replacement/conditional`、fit/evaluation窗口及knowledge_cutoff，不自造JSON参数 |
| 真实配方核对 | 已有 QE 配置、实际模型列和结果回执，只读 | 不把目录项、参考锚点等同模型输入；不修改 QE/Qlib/RD-Agent |

`context` 的日期过滤是指标/相关结果查询语义，不能当作研究信号区间。研究区间由实际运行spec及评价窗口声明。

### 4.4 输出与判读

完整 PIT 股票集合、有效日期、覆盖分母与缺失原因、IC/RankIC/相应稳定性、已有分组表现、官方已有收益风险指标、八期限预测指标、候选对可用存量及批内候选相关并列呈现。不存在的长周期真实净收益或夏普明确标为能力未提供，不用 h1 夏普填长周期；未定义权重及交易路径不计算伪净收益。

主用途不是唯一评价期限：例如h20用途仍展示八期限；5/20/60的研究比较只回答预先声明的问题，不每个期限单独选最有利方向。完整样本和共同成熟样本分列。

B 与 B+F 在相同样本、训练规则及预算下分别拟合；基准同时包含显而易见的做法和最接近存量，原料本身入 B 不自动构成缺陷。偏 RankIC 两侧秩变量同控制集残差化、残差不重排，退化报不可识别而非零；不把偏相关当充分或必要价值条件。

按日期配对报告用途对应差值和不确定性。`hac_maxlags`当前默认0，本轮比较spec必须明确选择理由及敏感性范围，不能默用0或机械宣称h−1解决全部依赖；稀疏事件或不连续日期无法满足原方法时报告描述性结果，不拼接成连续序列。多次选题/参数/用途的查看范围记录，未满足校正条件就声明无多重性保证。

综合结论分为：推荐指定用途的后续验证、保留明确待解问题、当前规格不支持。没有 IC/t 固定自动生死线；结论必须说明经济幅度、覆盖成本、历史稳定性、基准关系及反例。近期弱不是失效判决，长期均值强也不掩盖近期代价；组合指数超额、BF−B和独立因子指标互不替代。

## 5. W3：配方关系和非阻塞批量交接

### 5.1 先回答为什么是这个基准

逐候选提出加入/替换/条件用途，并复用已有独立评价及同口径相关，核对接收配方的实际列、公式方向、训练有效历史、模型、标签、股票池、预处理及已知缺失处理。

同月候选优先复用现有 AF 关系分析，不为追求“更完整”再训练研究代理模型。真正未知是能否在其有效学习历史内带来条件增量，应由有理由的 QE 对照回答，不用一轮轮相关统计替代。其他候选不得直接继承 AF。

候选间高相关按具体用途比较覆盖、稳定性与成本，不自动删除；低相关也不自动归入同批或同时加入。没有必要的相互补充问题就逐候选归因，不做组合遍历。

### 5.2 一次协调，按问题执行
