### 3.1 再平衡改变了什么

原B平均仅685笔新买、635笔退出，目标内已有持仓交易为0；B*新增平均2,599笔已有持仓买入、2,790.33笔已有持仓卖出，合计5,389.33笔股票—日实际成交。它们的平均双边金额约2.614亿元、费用约39.089万元；新买/退出费用下降部分抵消后，全账户费用净增35.970万元。

其中已有持仓买入金额约1.174亿元、费用30.447万元，观察到的平均费用强度约25.94bp；配置`open_cost=0.000095`、`close_cost=0.000595`、`min_cost=5`。这提示小额调仓及执行拆单的费用问题值得QE检查，但当前只拥有日聚合成交，不能据此证明某个minute子单分支或宣称收费BUG。

不能把全部行为概括为“卖掉上涨股、补回下跌股”：有前一日价格可核对的B*已有持仓买入中，前一日上涨金额6,975万元、下跌3,226万元；已有持仓卖出中，前一日下跌8,022万元、上涨3,590万元。其余平盘和缺少前一日持仓价格明确保留，未补行情。该事前一日分类是描述，不证明交易因果或最佳持有期。

### 3.2 名单路径并不相同，不能伪装严格单变量比较

B*对原B的目标名单不同日数为120/120/125，平均每日对称差12.064/5.392/6.840只。seed2026在首日就有3只替换：原B为688581.SH/603205.SH/300915.SZ，B*为688089.SH/603192.SH/688665.SH。六只在同一冻结AF、同一2026-03-31决策输入上的score均为`0.032799528972944775`。这证明首日差异处于并列分数边界，尚不证明具体排序实现根因。

其他两seed从4月9日起名单不同，后续路径依赖不能与每日调仓成本完全分开。R与B*的目标名单每天相同；实际持仓名单仅0/3/1日不同，符合目标相同但成交有差异的边界。

### 3.3 可核算的持仓/成交分解，不是执行因果结论

在至少一臂有真实日末持仓价格的股票—日上，使用同一价格单位作恒等式分解：

`净损益差 = 前日股数差×(今收−昨收) + (当日股数变化差×今收−成交金额差) − 手续费差`。

两臂都退出、无日末持仓价格的股票—日不造收盘价，保留gross残差。三seed均值如下，单位元：

```text
核算项                          B*−原B          R−B*
前日股数差持有至收盘             -936807.45       +48017.50
当日交易相对日末估值            -3466847.56       +95659.99
手续费差                        -359701.78        -4786.99
缺真实日末持仓价格的gross残差      +61109.42        -7956.22
总计                           -4702247.38      +130934.29
```

“当日交易相对日末估值”同时包含不同数量/标的/时点及实际成交价格，不等于滑点或执行算法错误。另按持仓集合分组，B*损失中约398.73万元出现在两臂日初、日末均持有的共同股票；这说明仅看行业命中率不足，实际权重路径很重要，但不隔离出任何一种策略机制的独立效应。

### 5.2 费用机制的可核算边界

### 5.3 唯一下一实验提案：自然新买预算调权（未批准、未执行）

以下由HMM窗口分析并提出，不再要求QE重做归因。消费对象从全部目标改为自然新买，属于新合同，不能沿用旧全持仓公式的批准状态。

1. **B0/R-entry两臂**：同一自然交易选股/退出/预算/整手/现金/执行路径，不调用绝对全仓目标生成器。原AF、topk=50、1亿元、seed42/2024/2026、125日及9月30日执行/估值保持。仅将并列明确为分数降序、instrument升序；买卖候选不能由set顺序决定。两臂同改并记录新baseline identity，旧B收益只作历史旁证。不得为修并列直接换整个当前策略类、捎带其他策略变化。
2. **调整集合**：每臂用自身当日真实持仓及原策略先生成目标S和自然新买J；J只含原本就要买、决策前未持有的股票。S按AF顺序分前ceil(n/2)及其余两组，再取`J_g=J∩S_g`，不将J重新均分。已有持仓不因risk补仓/减仓/退出；原正常退出和PIT强制退出照常。成交分化后允许原策略状态导致后续名单不同，不再承诺逐日名单或实际敞口一致。
3. **唯一建议公式**：当天完整131行业loss升序平均秩`r=(rank−1)/130`。`b_i`为原策略预算步骤后、整手与实际撮合前的新买目标金额；组内`B_g=sum(b_i)`、`mu_g=sum(b_i*r_i)/B_g`；建议`b'_i=b_i×[1+0.10×(mu_g−r_i)]`。空组/零预算不调，单股或同风险恒等。每组预取整金额守恒、单股变动90%～110%；原5%及单笔上限仍检验，越界显式失败，不clip后声称守恒。0.10是保持上轮量级的唯一提案值，不是继承批准、不调大或搜索。
4. **执行与现金**：两臂沿原可买价、现金、费用、整手、停牌/涨跌停、未成交及TAIL_BOOST路径，不因risk插额外卖单、目标外新股或全仓调仓。守恒只适用于相同决策状态的预取整金额，不保证整手后金额、实际投入/现金或后续两臂预算相同；这些差异须报告。禁止用历史已成交金额作为决策`b_i`。若原接口只有取整后数量，QE须明确最小前置钩子，不能另造整仓订单层。
5. **时间/缺失/身份**：复用原loss/20D/季度/10D、AF与同release mapping；decision=t、as_of=prev_open(t)，不额外shift。完整131状态不裁剪；J缺映射/loss或身份冲突沿原显式失败，不默认安全、不补价。非目标退出不为消费risk补分类。不扩千万元/Top20，不作10月在线采用。
6. **最小对照与停止**：先以已有决策状态/受控fixtures核对关闭overlay时与同一B0代码的目标、订单、退出及现金预算恒等，检验持仓不额外发单和空/单股/同风险/预算/上限。通过且新合同、运行获授权后，一组B0/R-entry各三seed，共六个新配对账户即可；旧15+6不重跑、不增加fit/推理。因为新基线修复了并列且回到自然交易，不能复用旧B收益替代新B0；这不是重验旧HMM。

正式回放须报告全期/Q2/Q3/月度扣费收益、回撤、换手、费用、现金及持仓路径；比较端到端消费规则，不声称逐日相同名单的纯条件调权效应。改善仍属已消费历史研究，不自动晋升。若保持原交易节奏必须同时改AF/池/执行算法或搜索参数，停止提案；若获批实验仍无合理增量，结束此消费分支，不自动再调κ或换模型。
