## R2的有界问题

检验“截至D已完整成熟的原候选五日组合收益状态，是否优于固定训练期组合均值，足以产生成本后增量”。这是日级机会状态，不是新增个股评分字段或参数网格。采用固定20个原决策日的经验分布，与静态同目标均值及不干预基线对照；只更新已成熟观测，不使用当前/未成熟未来结果。

区别与限制必须同时说明：旧causal Admission v2比较个股score/raw-market Ridge的静态与20日expanding重训，已负向停止；本问题是**原候选固定5TD组合的日级状态**、无回归系数重训，不是宣称因果更新从未研究。也不能仅凭“目标不同”证明新方法有价值；若本次无增量或无干预，精确停止，不再试10/40/60日窗口。
