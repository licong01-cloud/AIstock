# Task Plan: Paper V2 荐股功能分析与改进方向

## 目标 (Goal)
全面评估 Paper V2 荐股功能的现状，识别问题根源，并基于量化理论和行业实践提出系统性改进方案。

## 当前状态 (Current Status)
- **荐股胜率**: 60-70%（基于次日表现）
- **核心问题**: IC/RankIC 高的 loop 实际收益不高，排名前20准确度不够
- **状态**: 框架已实现，需要提升实际荐股能力

## 核心问题 (Key Questions)
1. **策略包优化**: 如何提升策略包质量和荐股准确性？
   - QE 研发演进方向
   - 策略包优选方法
   - 新方向探索

2. **评估指标选择**: 历史回测最优 vs RankIC 最高，哪个更适合荐股？

3. **组合策略**: 是否需要多策略包交叉验证？交集是否比单纯排名更有效？

4. **策略共享**: 量化交易策略与荐股策略包是否应该共享还是分开优化？
