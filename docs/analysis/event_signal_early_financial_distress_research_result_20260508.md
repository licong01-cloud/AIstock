## 9. 下一步研究顺序

1. 先研究 `financial_express_loss`：样本少但表现最稳定，优先分析行业/市值/年份稳定性。
2. 再研究 `financial_forecast_loss`：召回和 365 日命中率强，但短中期有反弹，需要加入严重亏损幅度、是否连续亏损、是否扣非亏损。
3. 研究多源共振：把 `source_count >= 3` 拆成具体组合，找出真正提升 precision 的组合。
4. 增加财务质量特征：现金流、扣非净利、资产负债率、ROE、商誉/减值、收入利润背离。
5. 只有当某类信号在多年、行业/市值分层和收益窗口中稳定有效，才进入 QE Loop1 离线 overlay。
6. 仍然不接入模拟盘/实盘，直到 overlay 证明风险收益改善。

阶段性结论更新：

- `financial_forecast_loss` 不能整体使用；真正有区分度的是 `续亏 + 预计亏损规模`，尤其是 `续亏 + >=10亿`、`续亏 + 1亿到10亿`。
- `续亏 + >=10亿` 的 365 日命中率为 32.80%，年度中位数为 31.03%；叠加 `tushare_fina_indicator + tushare_forecast` 后 365 日命中率升至 39.32%，但仍只允许进入离线 overlay 研究。
- `financial_express_loss` 的 T+20/T+60 收益更像风险信号，但未来 ST 命中率在 2023-2025 明显下降，当前只能作为“需要阈值细化”的研究对象，不能直接强交易。
- `tushare_express + tushare_forecast` 组合 365 日命中率为 14.44%，收益稳定性较好，但还没达到稳定高 precision，应继续拆分为亏损规模、连续亏损、扣非/现金流确认。
- `wan_unknown`、`loss_lt_100m_yuan`、`financial_positive_but_miss_expectation` 即使命中率看起来高，也被降级为 `needs_threshold_refinement`：分别对应金额缺失、小额亏损需市值归一化、不及预期定义过宽。
- 高 precision 但只有 2-3 个有效年份的交叉规则被标为 `reject_for_instability`，避免小样本把规则误升级。

下一步研究建议：

1. 先围绕 `续亏 + 预计亏损规模` 做市值/行业归一化，不先改交易模块。
2. 对 `financial_express_loss` 做最近年度衰退原因分析：区分政策/市场阶段、业绩快报披露滞后、是否已在预告阶段被消化。
3. 将候选规则用于离线 QE Loop overlay 之前，先增加同一脚本内的“按市值分层/行业分层/连续报告期亏损”研究。
4. LLM/PDF 仍不应提前进入：只有当结构化数据无法判定的公告类型进入候选后，再研究正文预处理和 LLM。
