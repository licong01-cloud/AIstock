## 1. 结论与取舍

**当前优先问题是风险信号在实际买入集合中的有效性和目标对齐，不是接线、数据补录或调权力度。** 本轮没有发现需要QE重跑或数据窗口补数的证据。原六账户平均净增益6.96bp仍成立，但不足以支持推广；本报告不新增显著性/阈值门禁。

1. 模型在实际新买股票上的10日亏损辨别力偏弱且季度差异大。跨seed去重后，同日风险—股票10日亏损秩相关全期0.0382，Q2为−0.0195、Q3为+0.1165。不能把全部样本混成一个pooled相关，也不能把三个seed当三条独立市场路径。
2. 在消费者真正可以调权的原AF组内，完整期的非并列成对排序一致率仅47.63%～48.33%；Q2约45.3%、Q3约54.5%～57.3%。这与日均秩相关并不矛盾：前者按非并列股票对计数，后者日期等权，零亏损/同一行业及较大初始建仓日的权重不同。两者都保留，不事后选择有利口径。
3. 已退出持仓中位持续5～6个交易日；但26.38%超过10日，另有150个未退出持仓。**固定10日目标与实际持有期并不一致，但尚不能证明这是效果偏弱的原因或5日模型优于10日模型。** 不据此搜索horizon或直接重训。
4. 高预测风险不等于低收益。Q3最高风险秩20%内实际买入股票的10日平均收益分别为+5.84%、+5.14%、+6.85%，仍可伴随下行损失；不能把风险值直接升级成硬禁买或总仓位减持规则。

本轮完成后：保留当前L2研究资产与已实现的低干扰消费入口，不晋升、不放大κ、不立即提交QE实验，也不退役整个HMM模块。现有证据不足以为一个新的精确模型/窗口/参数合同背书，因此没有编造“下一模型必然更优”的训练方案。

三个目标分开：

- 行业10日损失：原合同`max(0,1-product(1+r[t+j,L2],j=1..10))`，不是个股损失。
- 股票10日损失：`max(0,1-close[t+10]/close[t])`。另外分seed核对成交均价锚点；close-to-close不是实际可交易回报，不扣造假固定费用。
- 实际持仓损失：从首次实际买入至完全退出，汇总原生逐股净损益（已含真实费用），先计算`episode_return=净损益/该次实际买入金额`，再取`episode_loss=max(0,-episode_return)`；未退出保持右截尾，不填0，不假设在9月30日卖出。中间退出由原策略决定，因此该量具有策略依赖性，不可直接当新模型的通用训练标签。

所有day offset按原冻结交易日历计算。预测日`t`、特征as_of为前一交易日；不重复滞后。10日成熟边界与实际退出边界是两种不同缺失语义。

### 5.2 唯一值得继续论证的L2问题

**L2内成员股的下行损失分布，是否比行业组合均值的损失更能描述真实候选股票的风险，同时不把上行机会当作应删除的风险？** 这是下一设计的假设，而不是本报告已证明的解法。

当前标签先聚合行业收益再取终值负部，目标是行业组合损失；股票赢家和输家可以在聚合时互相抵消。即使完全预测这个目标，也不能等同于预测任意入选股票的亏损。对同一组权重、同一期限，`sum(w*max(0,-R_stock))`与`max(0,-sum(w*R_stock))`是不同量；这条数学关系**不**自动适用于原每日变动成员/权重的行业复合路径，需在同一固定PIT成员及锚点上对照才能归因。

本次Q2所选股票平均10日损失约4.28%～4.56%，对应行业平均约2.25%～2.50%；Q3则是所选股票约2.24%～2.49%、对应行业约2.90%～3.07%。这些不是同一总体，差异同时含Alpha选股、成员权重和行情路径，不能仅归因于聚合或据此直接重写标签。

因此下一完整包应先闭合**一个目标可行性对照与一份精确设计**：核对既有批准训练区间内可得的PIT成员、权重和个股收益，保持L2输出及现有特征/窗口作为控制，判断成员损失目标是否有新增可识别信息。机会收益分布同时报告，不自动增加第二模型。若这一步不能说明新增信息及适用场景，停止，不为了延长任务而启动fit。具体权重、标签、样本资格和独立评价区间尚未冻结，本文不是D1～D6批准合同。

不直接把本批QE最终选中股票或事后退出期写回训练标签；那会将策略及未来选择混进HMM通用目标。若未来需要历史Alpha条件化标签，必须先证明当时真实可得的Alpha预测，不允许用全期回填预测。仍只研究申万L2，不新增L1/大盘模型平台，不代改QE/荐股/LocalSIM。
