# LocalSIM逐账户名称与估值盈亏修复（BUG-1994）

日期：2026-10-20。关联问题：https://github.com/licong01-cloud/AIstock/issues/6377 。

用户在前一版重启后指出：策略名称不可读、总览大量指标为空、账户详情应分别展示资产和盈亏。本修复只更改只读展示投影与右侧页面，不修改账户、订单、成交、现金、持仓、回放状态、断点、行情或共享选股代码。数据库和依赖变更均为noop；用户后端不由本窗口重启。

## 修复与合同

1. 原生可读名称继续保留；机器名称改从账户冻结manifest对应的模型族、Alpha158启用状态和因子数量组合生成。旧manifest没有model_type时只提取model_id中的已认识模型族词，不显示种子身份，不维护策略包ID映射，不加载权重。冻结身份不匹配则明确待核验。生成名称不写回数据库。
2. 总览按策略账户分别展示总资产、持仓资产、现金、累计估值盈亏/收益率、持仓浮盈、估值日盈亏和今日盈亏；删除跨账户实时合计主卡。详情顶部始终读取本账户累计字段，区间过滤不会改变累计指标。
3. 累计估值盈亏与完整收盘区间解耦。以正式初始资金、完整成交与现金逐笔对应、现金桥接及持仓数量桥接证明fill-only账本无未解释净外部资金流，才显示NAV减正式期初资金。费用已在现金和NAV中计入，不再次扣减。未知分类、资金调整、缺失成交、持仓差异、非法数值或不明期初保持未知；不推算资金流。
4. 估值日盈亏使用前一交易日合法收盘至当前权威估值；首日使用已证明正式期初。两次盘中估值之间的变化独立标记，不能替代日盈亏。今日另外核对北京时间日期，过去估值不冒充今天。现有`/pnl`收盘区间、UNKNOWN、分页和导出合同保留。
5. 现金余额已知时正常展示；未单独记录可用/冻结现金则说明缺少分项。修正导出Blob URL过早释放，保留浏览器开始读取下载所需的生命周期。
6. 左侧导航、公共layout、全局CSS及菜单文件不变。表格固定合理最小列宽，在本表内部横向滚动；窄内容区卡片自适应，不修改导航宽度。
