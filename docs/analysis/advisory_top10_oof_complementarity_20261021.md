原研究唯一选定配置Ridge100保持，不从另外五配置重新择优。对每包/原D，
将原rank1～10各股与rank11～20各股组成100对；两股都有模型建议且模型严格更偏好后者，才记一次挑战。
诊断值为所有被挑战对的“后者五日净结果－前者五日净结果”之和除以固定100。
没有挑战为0；原Top20任何收益未知则该包/日诊断为null，不删股票或压缩原D轴。
每fold只读取截至该fold结束已成熟的H，未来/未知保持原语义。

同股票会进入多对，因此此数值**不是可执行Top10收益、收益增量或NAV**；它只测量模型与原排序分歧的方向。
包先等权、再日等权，置信区间用原126D轴的10D block同步重采样，不把股票对当IID。

覆盖≥80%、至少两个fold有干预；支持不足与负向区分。该规则不是生产门禁或确认标准。
