## 发现二：模型主要通过行情字段重排，属于显著改变选择

当前父分数两字段合计贡献的横截面标准差0.028394，六个行情字段合计0.351653，后者约12.385倍。第3折43个历史预测D的该比例中位数16.024倍；第一/二折约4.617/5.060倍。模型系数和时间同时变化，不能据此把表现差异纯归因为父权重、市场状态或训练人口。

当前模型Top10与原生Top10仅保留1只，换入9只；历史三折平均每日换入约7.275/7.558/7.442只。说明父包主要负责构造原Top50机会集，模型在其中大量改变短期顺序；不能称为只做少量纠错，也不能因贡献低就断言父模型无用。

当前逐字段贡献标准差主要来自atr14_close（0.294478）、ret_1（0.271477）、ret_5（0.227463）和volume_ratio_5_to_20（0.182751）。字段相关，标准差不能直接相加为信息占比，贡献分解不是独立因果归因，分数也不是预期收益率。

当前模型第10/11名的分数差为0.0500963，最小已知行情单坐标翻转距离为0.138394个原训练scale，限制坐标atr14_close。相同第3折模型历史该距离中位数0.034935，当前大于43个旧D中41个（经验分位95.35%）。因此本批并未显示比原持出期更窄的数学边界。

**该距离仅为ALGEBRAIC_SENSITIVITY_ONLY，不是实际价格误差或换股概率。** 父标准化分数与排名是同一父评分的派生字段，未独立扰动；行情字段也有共同约束。零斜率、缺失非可导、无建议及tie分别输出，没有用数学敏感性创建新策略或选择有利收益。
