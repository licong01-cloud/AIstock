# Bin NaN 数据对训练/回测的影响分析

## 整体统计

- 总单元格数: 108,509,544
- 总 NaN 单元格数: 43,346,232
- 整体 NaN 占比: 39.95%
- 总行数: 18,084,924
- 全 NaN 行数: 7,224,372
- 全 NaN 行占比: 39.95%

## 影响分析

### 1. 特征工程层面

- 高 NaN 比例会导致特征工程时填充策略（前向填充、均值填充）引入偏差
- 若使用滚动窗口计算特征，NaN 会拖累窗口内所有计算结果
- 部分模型（如树模型）可处理 NaN，但线性模型/深度学习通常需要预处理

### 2. 模型训练层面

- 训练样本中大量 NaN 会降低有效样本量，影响模型拟合能力
- 若使用掩码或特殊值表示 NaN，模型可能学习到“缺失”模式而非真实信号
- 对于时间序列模型，连续 NaN 会破坏时间连续性，导致预测失效

### 3. 回测层面

- 回测时若遇到 NaN，通常需要跳过该日期，导致交易机会减少
- 策略信号可能因 NaN 而延迟或失效，影响回测结果真实性
- 风险管理模块（止损、仓位控制）可能因 NaN 而误判

### 4. 建议缓解措施

- 使用更新后的 all.txt 重新生成 bin 数据，减少未上市区间的 NaN
- 在特征工程前根据上市日期过滤，只使用上市后数据
- 对 NaN 行进行专门处理（剔除、标记、使用独立模型）
- 在训练/回测时设置最小有效数据阈值，过滤掉 NaN 过多的股票
