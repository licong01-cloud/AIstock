# HMM 模型优化验证方案 - 使用 Qlib 数据

## ✅ 最终方案: 使用 Qlib bin 文件验证

### 为什么选择 Qlib 数据？

| 对比项 | 数据库 | Qlib bin | 优势 |
|--------|--------|----------|------|
| **速度** | 慢 (SQL查询) | **快** (内存映射) | ⭐⭐⭐⭐⭐ |
| **数据更新** | ❌ 前复权表未更新 | ✅ 及时更新 | ⭐⭐⭐⭐⭐ |
| **数据一致性** | 可能不一致 | ✅ 与QE实验相同 | ⭐⭐⭐⭐⭐ |
| **依赖** | 需要数据库连接 | 仅需文件系统 | ⭐⭐⭐⭐ |
| **可靠性** | 表结构可能变化 | 格式稳定 | ⭐⭐⭐⭐⭐ |

### 核心优势

1. **速度快**:
   - Qlib 使用内存映射读取 bin 文件
   - 比数据库查询快 10-100 倍
   - 预计 5-10 分钟完成验证

2. **数据可靠**:
   - 与 QE 实验使用完全相同的数据源
   - 避免数据不一致导致的误差
   - 前复权数据完整

3. **无需数据库**:
   - 不依赖数据库连接
   - 不受表结构变化影响
   - 更容易复现

## 📋 验证脚本说明

### 脚本位置
```
scripts/verify_hmm_qlib.py
```

### 数据源
```
qlib_bin/qlib_bin_20260311/
├── calendars/      # 交易日历
├── features/       # 股票特征数据
├── instruments/    # 股票列表
└── meta_export.json
```

### 验证流程

```
1. 加载 HMM 系数文件
   ├── 旧版本: 564b407f.../coefficients_preset_A_*.json
   └── 新版本: b2d5bcc6.../coefficients_preset_A_*.json

2. 从 Qlib 加载股票数据
   ├── 字段: $close, $change (涨跌幅)
   ├── 时间: 重叠时间段 (2026-01-26 ~ 2026-03-03)
   └── 股票: 全市场

3. 计算三个版本的收益
   ├── Baseline: 不使用 HMM
   ├── 旧版本: 应用旧 HMM 系数
   └── 新版本: 应用新 HMM 系数

4. 对比关键指标
   ├── 年化收益率
   ├── Sharpe 比率
   ├── 最大回撤
   ├── 胜率
   └── 累计收益

5. 生成对比图表
   ├── 累计收益曲线
   ├── 回撤曲线
   ├── 指标对比柱状图
   └── 改进幅度图
```

### 简化策略

**持仓策略**: 每日等权持有 top 50 股票
- 根据 HMM 调整后的收益排序
- 选择前 50 名
- 等权配置
- 每日调仓

**说明**:
- 这是简化策略，用于快速验证 HMM 系数的增量效果
- 实际策略可能更复杂（因子加权、风险控制等）
- 但足以评估 HMM 优化的方向性

## 🔧 如果遇到问题

### 问题 1: Qlib 未安装

```bash
pip install pyqlib
```

### 问题 2: Qlib 数据路径错误

修改脚本中的路径:
```python
QLIB_BIN_PATH = Path("qlib_bin/qlib_bin_20260311")
```

### 问题 3: 内存不足

减少股票数量或时间范围:
```python
# 在 load_qlib_data 中添加
instruments = instruments[:1000]  # 只取前1000只
```

### 问题 4: matplotlib 未安装

```bash
pip install matplotlib
```

或跳过绘图（脚本会自动跳过）
