# 策略自动执行说明

> **说明**: 本文档详细说明策略如何自动执行，以及 RealtimeQuoteSubscriber 服务的作用。

---

## 1. RealtimeQuoteSubscriber 服务说明

### 什么是 RealtimeQuoteSubscriber？

`RealtimeQuoteSubscriber` 是一个**实时行情订阅服务**，用于从 miniQMT 获取实时行情数据。

**功能**：
- 订阅股票实时行情（通过 xtquant）
- 接收行情回调推送
- 提供获取最新行情的接口

**当前状态**：
- ✅ 已实现，但**尚未集成到策略自动执行流程**
- ⚠️ 目前策略使用的是**定时调度**，不是事件驱动

### 两种执行方式对比

#### 方式1：定时调度（当前实现）✅

```
定时触发（如09:30）
   ↓
获取历史数据 + 实时行情更新
   ↓
计算技术指标
   ↓
判断交易信号
   ↓
自动执行交易
```

**特点**：
- ✅ 已实现并运行
- ✅ 策略调度器自动执行
- ✅ 无需人工触发
- ⚠️ 基于定时任务，不是实时触发

#### 方式2：事件驱动（未来扩展）⏳

```
订阅实时行情
   ↓
收到行情更新（回调）
   ↓
获取历史数据 + 最新行情
   ↓
计算技术指标
   ↓
判断交易信号
   ↓
自动执行交易
```

**特点**：
- ⏳ 需要集成 RealtimeQuoteSubscriber
- ✅ 真正的实时触发
- ✅ 延迟最低

## 2. 策略自动执行机制

### ✅ 当前实现：定时调度自动执行

**策略调度器** (`StrategyScheduler`) 已经实现了自动执行：

1. **启动时**：
   - 从数据库加载所有启用的策略
   - 根据 `schedule_config` 配置定时任务
   - 在后台线程中运行

2. **定时执行**：
   - 每日执行：`{"type": "daily", "time": "09:30"}`
   - 每小时执行：`{"type": "hourly", "time": ":00"}`
   - 每分钟执行：`{"type": "minute", "interval": 5}`

3. **执行流程**：
   ```
   定时触发
   ↓
   遍历策略配置的股票列表
   ↓
   对每个股票运行策略
   ↓
   策略自动判断买卖点
   ↓
   生成交易信号
   ↓
   自动执行交易（下单）
   ```

### ✅ 是的，策略运行后自动判断买卖点，不需要人工触发！

**工作流程**：
1. 策略调度器定时触发（如每日09:30）
2. 策略自动获取数据、计算指标、判断信号
3. 如果生成交易信号，**自动执行交易**（调用 QMT 下单）
4. 无需人工干预

## 3. 双均线策略支持15分钟线

### 当前实现

双均线策略目前**固定使用日线数据**（`period="3mo"`），不支持15分钟线。

### 需要修改

需要让策略支持**可配置的数据周期**：

**配置示例**：
```json
{
  "ma_short": 5,
  "ma_long": 20,
  "period": "15m",  // 新增：数据周期（15m, 1d等）
  "symbols": ["600519.SH"],
  "position_size": 0.1,
  "price_type": "LIMIT"
}
```

**支持周期**：
- `15m` - 15分钟线（日内交易）
- `1d` - 日线（日频交易）
- `1m`, `5m`, `30m` 等

### 日内交易场景

**已有持仓的情况下，根据15分钟线做双均线策略**：

1. **配置策略**：
   ```json
   {
     "ma_short": 5,
     "ma_long": 20,
     "period": "15m",
     "symbols": ["600519.SH"],
     "position_size": 0.1
   }
   ```

2. **调度配置**：
   ```json
   {
     "type": "minute",
     "interval": 15
   }
   ```
   说明：每15分钟执行一次

3. **执行流程**：
   - 每15分钟自动执行
   - 获取15分钟K线数据
   - 计算MA5和MA20（基于15分钟线）
   - 判断交叉信号
   - **自动执行买卖操作**

## 4. 字段对齐问题

### 当前字段映射

#### 策略使用的字段
- `close` - 收盘价（用于计算均线）
- `volume` - 成交量（趋势跟踪策略使用）

#### xtquant 实时行情字段
- `lastPrice` - 最新价（对应 `close`）
- `volume` - 成交量 ✅ 已对齐
- `open`, `high`, `low` - 其他价格字段

#### TDX/Tushare 实时行情字段
- `price` - 当前价格（对应 `close`）
- `volume` - 成交量 ✅ 已对齐

### ⚠️ 字段对齐问题

**问题**：
- xtquant 返回 `lastPrice`，策略使用 `close`
- TDX/Tushare 返回 `price`，策略使用 `close`

**当前处理**：
- ✅ 策略代码中已做转换：`current_price = quote.get("lastPrice")` 或 `quote.get("price")`
- ✅ 更新到 DataFrame 的 `close` 列

**建议**：
- 统一字段命名，或创建字段映射层

## 5. 完整自动执行流程

### 场景1：日频策略（每日执行）

```
1. 后端启动
   ↓
2. 策略调度器启动
   ↓
3. 加载策略配置（从数据库）
   ↓
4. 设置定时任务（每日09:30）
   ↓
5. 定时触发执行
   ↓
6. 对每个股票：
   - 获取历史数据（3个月日线）
   - 获取实时行情（更新最新价格）
   - 计算MA5和MA20
   - 判断交叉信号
   - 如果有信号，自动下单
   ↓
7. 记录执行结果（数据库）
```

### 场景2：日内策略（15分钟线）

```
1. 配置策略周期为15分钟
   ↓
2. 设置调度为每15分钟执行
   ↓
3. 每15分钟自动执行：
   - 获取15分钟K线数据
   - 获取实时行情（更新最新价格）
   - 计算MA5和MA20（基于15分钟线）
   - 判断交叉信号
   - 如果有信号，自动下单
   ↓
4. 持续监控和执行
```

## 6. 如何配置策略自动执行

### 步骤1：创建策略配置

```json
{
  "strategy_id": "ma_cross_15m_001",
  "strategy_name": "双均线策略（15分钟）",
  "strategy_type": "MA_CROSS",
  "enabled": true,
  "config_json": {
    "ma_short": 5,
    "ma_long": 20,
    "period": "15m",  // 15分钟线
    "symbols": ["600519.SH"],
    "position_size": 0.1,
    "price_type": "LIMIT"
  },
  "schedule_config": {
    "type": "minute",
    "interval": 15  // 每15分钟执行
  }
}
```

### 步骤2：策略调度器自动执行

- ✅ 后端启动时自动启动策略调度器
- ✅ 自动加载启用的策略
- ✅ 根据调度配置自动执行
- ✅ **无需人工触发**
