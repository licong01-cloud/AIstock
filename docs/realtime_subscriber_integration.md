# RealtimeQuoteSubscriber 集成说明

> **说明**: 本文档说明 RealtimeQuoteSubscriber 如何集成到策略自动执行流程。

---

## ✅ 已集成

`RealtimeQuoteSubscriber` 已集成到策略调度器中，支持**事件驱动的实时触发**。

---

## 集成方式

### 1. 策略调度器集成

**位置**: `backend/schedulers/strategy_scheduler.py`

**功能**：
- 策略调度器启动时，自动启动实时行情订阅服务
- 如果策略配置了 `"type": "realtime"`，自动订阅实时行情
- 收到行情更新时，自动触发策略执行

### 2. 实时触发流程

```
策略配置 schedule_config: {"type": "realtime"}
   ↓
策略调度器订阅实时行情
   ↓
收到行情更新（回调）
   ↓
自动触发策略执行
   ↓
策略获取数据、计算指标、判断信号
   ↓
自动执行交易（如果有信号）
```

---

## 配置方式

### 方式1：表单配置（推荐）

在策略管理页面：

1. **执行类型**：选择"实时（行情触发）"
2. **其他参数**：正常配置

**配置示例**：
- 执行类型：`实时（行情触发）`
- 数据周期：`15m`（15分钟线）
- 股票代码：`600519.SH`

### 方式2：JSON配置

**调度配置**：
```json
{
  "type": "realtime"
}
```

**完整配置示例**：
```json
{
  "strategy_id": "ma_cross_realtime_001",
  "strategy_name": "双均线策略（实时触发）",
  "strategy_type": "MA_CROSS",
  "enabled": true,
  "config_json": {
    "ma_short": 5,
    "ma_long": 20,
    "period": "15m",
    "symbols": ["600519.SH"],
    "position_size": 0.1,
    "price_type": "LIMIT"
  },
  "schedule_config": {
    "type": "realtime"
  }
}
```

## 执行方式对比

### 定时调度（原有方式）

```
定时触发（如09:30）
   ↓
执行策略
   ↓
判断信号
   ↓
执行交易
```

**特点**：
- ✅ 固定时间执行
- ✅ 适合日频策略
- ⚠️ 不是真正的实时

### 实时触发（新增方式）

```
订阅实时行情
   ↓
收到行情更新（回调）
   ↓
立即执行策略
   ↓
判断信号
   ↓
执行交易
```

**特点**：
- ✅ 真正的实时触发
- ✅ 延迟最低
- ✅ 适合日内交易

## 使用场景

### 场景1：日频策略（定时调度）

**配置**：
- 执行类型：`日频（每日执行）`
- 执行时间：`09:30`
- 数据周期：`1d`（日线）

**适用**：
- 双均线策略（日线）
- 趋势跟踪策略（日线）

### 场景2：日内策略（实时触发）

**配置**：
- 执行类型：`实时（行情触发）`
- 数据周期：`15m`（15分钟线）

**适用**：
- 双均线策略（15分钟线）
- 趋势跟踪策略（15分钟线）
- 需要快速响应的策略

### 场景3：日内策略（定时调度）

**配置**：
- 执行类型：`分钟级（定时执行）`
- 执行间隔：`15`（分钟）
- 数据周期：`15m`（15分钟线）

**适用**：
- 不需要立即响应的日内策略
- 降低执行频率，减少资源消耗

---

## 注意事项

1. **实时触发**：
   - 需要 miniQMT 已启动并登录
   - 需要 xtquant 可用
   - 会持续订阅行情，消耗资源

2. **订阅数量**：
   - 单股订阅数量不宜过多（建议 < 100）
   - 订阅过多可能影响性能

3. **回调性能**：
   - 回调函数应快速执行
   - 避免在回调中执行耗时操作

4. **错误处理**：
   - 订阅失败会记录日志
   - 策略执行失败不影响其他策略
