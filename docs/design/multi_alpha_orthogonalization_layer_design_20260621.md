# 多 Alpha 正交化层 设计稿(2026-06-21)

> 定位:蓝图 [附录 B.4.1](storage_signal_layer_unified_blueprint_20260618.md) 的落地设计。组合层重心从"更好的 combiner"转向"**组合前正交化**"。本稿为设计草案,走 worktree → PR → Tier2;实现分期(§8)。

## 0. 依据
- 验证 run 实证:6 腿组合(equal 2.4373 / ic 2.4591 / orth 2.4794)全输最强单腿 2.667。
- 根因:预测值高相关(P3-A avg|corr| 0.6–0.72,a1↔a3=0.815,a5↔a7=0.858)。
- 理论:`w=γ·C⁻¹·α`,高相关→冗余腿边际→0,组合增益只来自不相关分量;`IR=IC·√breadth`。
- 机构标准:组合前正交化(对称正交化 / 残差回归 / PCA),而非朴素加权原始预测。

## 1. 目标与双重作用
1. **预处理**:把候选腿预测转成"相互正交的独立信号"再喂 combiner → 组合分散化收益变真。
2. **诊断**:量化每腿的"独立预测贡献"(正交 IC / 残差方差占比)→ 既是选腿/砍腿依据,也是"该不该继续在这组腿上组合"的判官。

## 2. 方法选型
| 方法 | 说明 | 取舍 |
|---|---|---|
| **对称正交化(Löwdin / Barra 式)** ⭐主方案 | 对腿分数矩阵做 `S^(-1/2)` 变换(S=腿间相关阵),得到与原始最接近、彼此正交的信号 | **order-independent**、可解释、与原信号最接近,行业标准 |
| **Gram-Schmidt 顺序残差化** 备选/诊断 | 按优先序,每条新腿对已选腿集回归取残差 | order-dependent(主腿保全、后续留残差),适合"主腿+卫星"语义,顺序敏感 |
| **PCA 取前 K 主成分** | 协方差前 K 个正特征向量,丢低方差方向 | 降维好,但 PC 是腿的线性组合、可解释性弱 |

**推荐**:主用**对称正交化**;同时输出 **GS 残差 IC**(按 standalone 强度排序)作为"每腿增量贡献"诊断(语义直观:主腿→卫星)。

## 3. 无泄漏口径(关键)
- **逐 date 截面正交化**(主口径):相关阵与变换在**当日截面**上估计并应用 —— 分数是当日可得的预测,不含未来信息 → 天然无泄漏。
- **walk-forward**(可选):相关阵在过去窗估、应用到 OOS 当日(与 combiner walk-forward 一致,结构更稳)。
- 复用 `normalize_prediction_frame` 与 panels/combiner 的日期对齐口径,不另起。

## 4. 数据流 / 接口
```
候选腿 pred frames (trade_date, instrument, score)
  → normalize (复用)
  → 正交化层 (逐date截面: 对称正交化 / GS残差)
       ├─ 输出A: 正交化信号 frames → combiner (equal/ic/rank-fusion…)
       └─ 输出B: 诊断 = 每腿正交IC / 残差方差占比 / 与原信号相关 / 有效独立腿数
  → combiner → combined score → QE pred-backtest → eval
```
- 新模块 `backend/services/multi_alpha/orthogonalize.py`;复用现有 `orthogonality.py`(P3-A 相关/Jaccard 已在此)。
- combiner 侧:加"组合前 orthogonalize 选项"(默认关,opt-in),不破坏现有 scheme/默认行为。

## 5. 诊断指标(绑定附录 B.4.3 鲁棒/广度 KPI)
- **每腿正交 IC**:腿正交分量 vs forward return 的 rank-IC。高=唯一预测贡献;近 0=冗余。
- **残差方差占比**:正交分量方差 / 原分数方差。低=被其他腿解释殆尽。
- **有效独立腿数(breadth 代理)**:由相关阵特征值估(participation ratio)。
- 以上进 §5.4 每策略包指标,作选腿/砍腿与"组合是否成立"的依据。

## 6. 预期结果与解读(诚实预判)
- 6 腿高相关(0.6–0.86)下,预计**多数腿正交 IC 偏低** —— 正交化**不会凭空造 alpha**,而会**量化确认"这 6 腿独立信息有限"**。
- 两种有用结论:
  1. 若某 **2–3 腿正交 IC 仍显著** → 用正交化子集组合,可能小胜单腿(真分散);
  2. 若**普遍偏低** → 实证支持附录 B.4.2"必须跨 horizon / 新信号源",而非继续在这 6 腿调 combiner。
- 故正交化层既是预处理,也是**下一步该往哪走的判官**。

## 7. 验收口径
- **无泄漏**:断言逐 date 截面变换不含跨期信息;正交化后腿间相关 ≈ 0(数值容差)。
- **正确性**:对称正交化输出 与输入相关性最大化 且 互相关→0(单测构造已知相关腿验证);GS 残差对已选腿正交。
- **诊断**:构造"一条腿=另一条腿线性组合"→ 其正交 IC / 残差方差 ≈ 0。
- **衔接**:正交化信号能跑通现有 pred-backtest 原语,出 scheme_result。

## 8. 落地节奏(MCP-first,与现有平台一致)

- **Tier 2**(待并行 bug 修复 + 平台恢复):接线为 combine-backtest 的 `orthogonalize` 选项 + 诊断落库;与执行层一起。
- 均走 worktree → PR → Tier2 审。
