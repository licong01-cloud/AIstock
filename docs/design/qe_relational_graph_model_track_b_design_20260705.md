## 1. 背景：已确立的事实与必须承认的偏差

### 1.1 Phase0 已确立的结论（2026-07-04/05）

全样本 filtered_pool_20260428、disable_alpha158、8–10 趋势因子：

- **趋势方向成立**：LGBM/LSTM/TCN 三模型的 rank_ic 随 label horizon 单调走强，**h20（QE 上限）最优**——与反转书（短周期最强）形态相反，证明这是独立的信号结构。
- 最优单腿（单窗单种子，开发窗口径）：
  - LSTM h20：rank_ic 0.098 / 年化 0.42（cagr 0.80）/ Calmar 6.53
  - LGBM h20（10 因子）：rank_ic 0.098 / 年化 0.41 / Calmar 5.2，**双种子 0.0976 vs 0.0979 极稳**
- 最优 10 因子集（LGBM factor{3,5,8,10}×h{5,10,20} 消融验证，8→10 单调提升）。
- **时间维 Transformer（qlib `pytorch_transformer_ts`）实测无效**（rank_ic≈0），接入 bug（BUG-592/593）修复后仍无效——是模型类别不对，非工程问题。

### 1.2 必须承认的三个偏差（本设计的出发点）

上述数字**不能直接当作预期收益**，存在三个系统性偏差，全部列为地基级修正项（§5.1、§7 P0）：

1. **单窗体制偏差**：测试窗 2024-02→2026-03 恰为 924 行情后的顺风段。截至 2026-06，**大部分传统行业股价已跌回 924 前水平**——即测试窗本质是**一次往返行情的上半场**。只在上半场验证过的趋势策略是教科书级陷阱；2022 熊市、2023 震荡、2024-01 微盘踩踏均不在测试窗内。
2. **选择偏差 + 多重比较**：h20、10 因子、最优模型都是在**同一窗口**选出的（已跑 ~50 loop）；种子 std 只度量训练噪声，不度量窗口噪声。按 QE 方法论的多重比较校正（√(2·lnN)≈2.4–2.8），最优数字须打折后才能作基线。当前窗口定性为**开发窗**，所有数字标注 in-sample-selected。
3. **成本口径未钉死**：0.42（annualized_return）与 0.80（cagr）两口径并存，且 QE 嵌套分钟执行存在已知的 cost 记录缺口。定任何横杆之前必须用 execution truth audit 核定这些数字是否含真实成本。

**诚实预期**：动量/题材类策略实盘 ≈ 回测的 1/2~1/3 是行业经验；叠加体制混合，本书混合体制下的合理预期为**年化 30–60% 区间**（若鲁棒性验证通过），不以单窗 118%/80% 为锚。

### 1.3 关键判别：两种 Transformer（已定论）

## 2. 战略定位：资金规模与「反中性化」路线

### 2.1 资金三档与优化方向

topk25 满仓的单票仓位与小盘股（日成交 5000 万–3 亿）参与率：

| AUM | 单票仓位 | 参与率 | 定性 |
|---|---|---|---|
| **1000 万（当前）** | ~40 万 | 0.1–0.8% | **当前设计的最优区**，冲击可忽略 |
| 1 亿 | ~400 万 | 1.5–8% | 同方向 + 执行升级：topk 加宽至 50、建仓拉长 2–3 日、参与率上限、涨停排队位次开始要紧 |
| 10 亿 | ~4000 万 | 小盘不可容纳 | **质变 = 换策略**：topk 100–300、中大盘、更长 horizon、部分中性化 |

**结论**：1000 万→1 亿是「同一策略 + 执行工程」；1 亿→10 亿是「换策略」。**现阶段按 1000 万设计，不为 10 亿做设计**，但留三个零成本期权：①组合层保持容量可扩架构（已有）；②**模拟盘起即记录参与率/成交占比分布**（将来扩容判断的数据基础）；③因子库对容量敏感因子（小盘偏置类）与容量友好因子分开标注。

### 2.2 小资金优势与「反中性化」的理性依据

头部机构做行业中性，**不是因为中性 alpha 更高，而是规模逼的**（无法在题材中快进快出、产品承诺稳定超额、回撤约束）——他们主动放弃板块方向 alpha 换容量。小资金不受这些约束：集中持有容量受限角落（小盘、题材）的 alpha、快速轮动无冲击。**「反中性化、抓热门板块」对 1000 万是结构性正确的选择。**

但须纠正对比谬误：**118%/80% 是单窗顺风回测，头部机构的 ~50% 是穿越实盘衰减后的净值**——两者不可比。小资金优势成立，预期锚定 §1.2 的诚实区间。

### 2.3 书级风控三件套（小资金真正的风控）

小资金不需要中性化，但集中持小盘题材票的死穴是**尾部退出流动性**（2024-01 微盘踩踏 = 连续跌停出不去）。趋势书上线前必须落：

1. **回撤刹车（书级）**：书级回撤阈值触发降仓/停买。
2. **单板块集中度上限**（建议 ≤35%，热门板块策略尤其需要）。
3. **尾部流动性预案**：跌停/流动性枯竭情景的退出规则（利用真实涨跌停分钟数据可回测该情景）。

## 3. 目标与非目标

### 3.1 目标
1. **把评估地基做实**（真样本外 + 滚动多窗 + 成本口径 + 涨停可成交性），使趋势腿定案数字可信。
2. 硬化趋势腿候选 **A（LSTM/TCN h20）与 B（LGBM h20）**，并用低成本手段（LTR loss、种子集成、补因子、有界调参）再推一档。
3. 开辟 **Track A'（分钟微观结构因子）**：验证日内结构信息对 h20 趋势（尤其启动识别）的增量。
4. 接入**关系/图模型双探针（HIST-industry + MASTER）**，用现成行业邻接验证「板块关联」在本项目 A 股数据上的增量；为概念图（Track C）铺路。
5. 成书：与反转书正交核验、体制门控、书级风控，进入组合层与模拟盘。

### 3.2 非目标
- 不改 `GeneralPTNN` 本体、不改 LGBM/LSTM/TCN 现有路径、不改 QE 数据装载主干（方案 A，§6.3）。
- 不为 10 亿资金规模设计；不在关系探针验证前采集概念数据。
- 不追求图模型「一定超过 LGBM」——增量与否是待验证实证问题，fail-fast。
- 股票池不变（filtered_pool_20260428 + `shsz_st_pit_active_v1`）。

## 5. 评估口径与判定门

### 5.1 地基级（评估纪律，适用于一切实验）

1. **真样本外（最高证据等级）**：数据更新至 2026-06 后，**冻结现有配置**（LSTM h20 / LGBM h20 10 因子，零改动）直跑 2026-04~06。该窗从未被任何选择触碰，且恰为**分化/逆风体制**（传统行业跌回 924 前）——直接检验「h20 能否及时逃出塌陷行业、集中进幸存热门板块」这一核心假设。
2. **滚动多窗（定案门，非加分项）**：现有数据内做 walk-forward（如 train18-21→test22；train18-22→test23；train19-23→test24H1），覆盖 2022 熊、2023 震荡、2024-01 踩踏。**验证工件与生产工件分离**：验证用滚动窗，生产模型仍用全量训练——不牺牲训练跨度。
3. **长历史方向验证（可选加强）**：筹码约束只绑 1–2 个因子；用**去筹码缩减因子集**回溯 2012–2018（含 2015 疯牛-股灾-熔断），验证「趋势因子 + h20」的**方向命题**跨体制成立性（非生产模型本身）。
4. **成本口径核定**：用 execution truth audit 确认回测数字是否含真实成本（已知嵌套分钟执行 cost 记录缺口）；此后所有横杆一律用**成本调整后年化**。
5. **涨停可成交性（趋势特有）**：统计 topk 信号中涨停不可成交比例及剔除后年化——趋势追涨的信号高频落在涨停日，此项可能显著砍账面收益（反转策略无此死角）。利用已有真实分钟涨跌停价数据。
6. **重叠标签推断修正**：h20 标签逐日截面 → 有效独立观测 ≈ 天数/20，ICIR 显著性被高估 ~4 倍（相对 h5）；评估脚本用非重叠采样或 Newey-West 修正。
7. **保守横杆**：基线 = 种子均值 − 1×std，再按多重比较（√(2·lnN)）打折；新窗口上**只验证不选择**。

### 5.2 腿级判定门（同池同窗同 h20，任一不过即 no-go，诚实记录不硬凑）

1. **信号**：rank_ic ≥ 保守横杆（§5.1.7）。
2. **绝对年化（第一优先级）**：成本调整后年化 ≥ 基线，Calmar 不显著恶化。
3. **正交性**：与既有腿（LGBM/LSTM）截面预测低相关——低相关才有独立腿价值（多腿组合核心，非单腿最强）。
4. **鲁棒性**：多种子均值±std + 滚动多窗分窗一致（沿用 macb 鲁棒 KPI）。
5. **no-go 范围校准**：探针阴性只否定该探针的具体命题——**Track B 行业图阴性不否定概念方向**（行业信息已以标量形式在因子中，行业图检验力天然有限；概念≠行业）；Track A' 典型集阴性才否定 LLM 分钟挖掘的前提。

### 5.3 书级判定门（趋势书成书前）

1. **与反转书正交（书级硬门）**：趋势书任何腿定案前，核验其截面预测/持仓与已上线反转书（a1_plus3_LSTM + FUNDGROWTH）低相关——证明是「另一本书」而非反转换皮；高相关则不计入趋势书。
2. **换手/容量/成本门（1000 万口径）**：换手率、小盘冲击、年化成本侵蚀量化确认；最终口径 = 成本调整后年化。
3. **书级风控三件套落地**（§2.3）。
4. **体制门控**：趋势书在震荡市持续失血是已知属性；组合层按体制（市场宽度/波动率）在反转书/趋势书间调配敞口（MASTER 的 market-gating 是同一思想的模型内版本）。
5. **模拟盘穿越逆风体制**：当前实盘环境接近逆风（§1.2），上线前先在 paper-v2 穿越当前体制。

## 6. 技术设计

### 6.1 Track A：趋势腿硬化与低垂果实

- **多种子硬化（进行中）**：GPU `qe_20260705_004409_4437`（LSTM/TCN h20×5seed×10 因子，wsl2-5080 2 并行）+ CPU `qe_20260705_004509_561a`（LGBM h20×8seed，node1 4 并行）。
- **LTR loss 实验（基础设施现成）**：平台已有 `AIStockGeneralPTNNLTR` + `approx_ndcg_at_k`（composer LTR 键在位）。目标是 topk25 组合，NDCG@k 与目标对齐优于 MSE。实验：LSTM h20 + `ltr_loss_mode=approx_ndcg_at_k`。
- **种子集成（零额外训练成本）**：A 硬化的 5 种子**平均预测**作为集成腿评估（deep ensemble 业内标配），而非只算 std 挑单个。
- **补因子**：先在因子库核实候选（如 RSQR20 等历史好但未被选上的），存在则**正交增量**（一次 1–2 个，按 §5.2 校验，不激进）。
- **有界超参微调**：LGBM（叶数/学习率/正则）、LSTM（hidden/dropout/lr）在已验证区间小步微调；以种子均值±std 判定，不追单点。

### 6.2 Track A'：分钟微观结构因子（两阶段）

**定位**：分钟数据不做分钟频交易，做**分钟→日频聚合特征**。与「趋势启动识别」强契合：主力吸筹/试盘痕迹先现于日内结构，后现于日线趋势。数据已在手（分钟线含真实涨跌停价），聚合后即普通日频因子，**走现有因子管线（逐因子立即入库），QE 侧零改动**。

**拥挤度分层判断**：日频公开因子（Alpha158 类）拥挤度最高；**分钟级公开因子（券商金工报告族）拥挤度显著更低**（数据/算力门槛过滤参与者），对 1000 万小盘 h20 池仍有残值——值多少以实测为准。

**阶段 M1（人工典型集探针，先行）**：实现 ~10 个文献验证度高的分钟→日频因子，全历史（2018-08 起）一次性批回填（远端 CPU 可分担）+ 每日增量，因子库常规注册与 IC 评估，然后加入趋势腿因子集做**增量消融**（同 §5.2 门）。候选清单（按与趋势启动的相关性排序）：

| # | 因子 | 捕捉什么 |
|---|---|---|
| 1 | 尾盘 30 分钟收益占比 | 机构尾盘建仓行为 |
| 2 | 涨停封板强度/开板次数（用真实涨停价） | 题材强度与承接力（趋势策略特有） |
| 3 | 聪明钱指标（\|r\|/√v 加权 VWAP 偏离） | 大资金参与痕迹 |
| 4 | 隔夜跳空 vs 日内收益分解 | 信息驱动 vs 情绪驱动 |
| 5 | 日内收益偏度/峰度 | 拉升结构 vs 出货结构 |
| 6 | 量能分布集中度（volume profile HHI） | 吸筹/试盘的量能形态 |
| 7 | 开盘 30 分钟动量与竞价异动 | 隔夜信息定价速度 |
| 8 | 下行波动占比 | 抛压结构 |
| 9 | 分钟大单量占比时序模式（早盘 vs 尾盘） | 主力节奏 |
| 10 | 实际波幅/振幅比 | 控盘度 |

**阶段 M2（LLM 驱动挖掘，条件触发）**：仅当 M1 证明分钟信息有增量后启动。复用**现有 RD-Agent/CoSTEER 因子演进基础设施**，将 exec 沙箱数据快照扩展至分钟聚合视图，让 LLM 在「分钟→日频聚合表达式」空间内演进（即用户所指清华 LLM 分钟频因子方案的思路，适配为聚合表达式生成）。价值判断：LLM 挖掘的意义不在魔法公式，而在**我们自己的池/周期/风格上系统化搜索非拥挤组合**；先决条件 = M1 阳性（否则是在未验证的矿脉上先买挖掘机）。

### 6.3 Track B：关系/图模型（HIST-industry + MASTER 双探针）

**双探针决策（v2 修订）**：方案 A 的**截面重组层是共享基础设施**（一次性成本），在其上并行两个探针、归因清晰、边际成本小：
- **HIST-industry**（已定首选，2026-07-05）：预定义概念图 = `sw_index_member` PIT 行业成分 + 隐藏概念模块学潜在联动；检验「显式行业结构」的增量；是 Phase3 概念超图的同框架前身。
- **MASTER**（v2 升为并行探针）：截面 Transformer（市场引导门控），**不需要任何邻接 artifact**——是「跨股票注意力有没有用」的最纯净、管线最省检验。
- 检验力预警（诚实声明）：行业信息已以标量因子形式在特征中（Industry_Momentum 等），行业图的先验增量有限；HIST 的论文威力主要来自**动态概念**（多归属、时变），行业成分近似静态单归属。故 **Track B 阴性 ≠ 关系无 alpha ≠ 概念无价值**（§5.2.5）。

**接入方式（方案 A，已确认）**：自定义 code_text 模型注册 `aistock_model_catalog`，走与 LSTM/TCN 相同的自定义路径；model.py 内自带 **cross-sectional 数据整形层**（fit/predict 内按 trade_date 把面板数据重组为截面批），不改 QE composer/dataset 主干。方案 B（新增 CrossSectionalDatasetH 分支）仅当方案 A 不可行再评估。

**工程要点**：
- **显存预算**：截面批（~4000 股×每日）远大于逐股票窗口批——图/截面模型 loop 预计需 **wsl2-5080 node_parallelism=1**（区别于 LSTM/TCN 的 2 并行），VRAM 预算按整日批估算，构建期实测定并行度。
- **PIT 行业邻接构建器**（离线只读 artifact）：成员判定 `in_date<=t AND (out_date IS NULL OR out_date>t)`；默认申万 L2 同业邻接（可行归一化/自环）；稀疏存储 + 版本化（快照日期、股票池 sha）；随 workspace 分发；单测覆盖 out_date 边界。仅 HIST 需要；MASTER 不需要。
- **停牌/缺失掩码**：截面批须与当日可交易池对齐，停牌掩码处理。

**特征底料（已决策）**：
- **Alpha360 原始量价 = 底料，不入因子库**：本质是 `Ref($field,i)/$close`（6 字段×60 天滞后归一化 = 360 维，qlib `Alpha360DL.get_feature_config` 规范），是数据装载 spec 非命名 alpha。落地 = **自定义模型 handler 即时生成**（与 qlib HIST/GATs 原生一致、零因子库改动、可复算）。备选「基础特征包 spec 登记」仅当治理强制。`$vwap` 是否在 bin 中**构建期核验**，无则 amount/volume 补。
- **私有趋势/筹码/资金流/基本面因子 = 差异化主力**（走因子库常规流程）；**Alpha158 择优子集 = 补充非主力**（拥挤度高）；**关系结构 = 本轨道核心赌注**（公开因子不含的维度）；M1 分钟因子验证后同样纳入底料。

### 6.4 Track C：概念板块数据源（采集口径）

| 源 | tushare 接口 | PIT 成分 | 历史 | 定位 |
|---|---|---|---|---|
| **THS 同花顺（主源）** | `ths_index`/`ths_member`（in_date/out_date）/`ths_daily` | 有 | 长（~2016+） | 回测骨架 + PIT 概念超图 |
| DC 东财 | `dc_index`/题材成分 | 部分 | 短（~2020+） | 短周期情绪/涨停/游资叠加层 |
| TDX 通达信 | tdx 概念板块分类/成分/行情 | 弱 | 弱/漂移 | 不作回测主源（tqcenter.py 可直连实时） |

采集走 `add-tushare-dataset` skill；产出按日 PIT 成分矩阵（多归属→超图/二部图），版本化 + 反泄漏单测。**触发条件独立判断**（§5.2.5）：Track B 行业探针阳性是充分非必要条件；若 2026Q2 分化体制证明题材轮动是主要收益来源，概念数据可独立立项。上层模型：HIST（概念版）/ STHAN-SR（超图，多归属正解）。

## 7. 分阶段实施步骤

### P0 — 评估地基（最高优先；P0.1 与 A 硬化实验并行即可开始）
- P0.1 **真样本外**：数据更新至 2026-06（用户侧管线）→ 冻结配置（LSTM h20 / LGBM h20 10 因子）直跑 2026-04~06 分化体制。**本计划中证据等级最高、成本最低的单个行动。**
- P0.2 **成本口径核定**（execution truth audit）+ **涨停可成交性统计**（topk 信号涨停占比、剔除后年化）。
- P0.3 A 硬化实验（GPU 4437 / CPU 561a）收口 → 按 §5.1.7 产出**保守横杆**（含多重比较折扣）。
- P0.4 **滚动多窗 harness**（2022/2023/2024-01 逆风窗）+ 可选去筹码长历史方向验证。
- 交付：真样本外报告、成本核定结论、涨停统计、保守横杆表、滚动窗结果。**门：地基全绿才进入腿定案。**

### P1 — 低垂果实（Track A 迭代 + Track A' 典型集探针，双节点并行）
- P1.1 LTR loss 实验 + 5 种子集成评估（§6.1）。
- P1.2 补因子（RSQR20 等核实→正交增量）+ 有界超参微调（远端 CPU 因子变体 / GPU 超参，分节点）。
- P1.3 **Track A' M1**：~10 个分钟→日频典型因子批回填 + 因子库注册 + 增量消融（§6.2）。
- P1.4 更新趋势腿 A/B 定案数字（成为 Track B 要超越的最新横杆）。
- 交付：腿 A/B 迭代后稳健数字；分钟因子增量结论（决定 M2 是否启动）。

### P2 — 关系双探针（Track B；正式走 feature workflow）
- P2.1 隔离 worktree：**共享截面重组层** + HIST-industry + MASTER 两个自定义模型（code_text）注册；PIT 行业邻接构建器（仅 HIST 需要）；Alpha360 即时 handler（+已验证的私有/分钟因子底料）。
- P2.2 冒烟：h20 单种子，能训练/过 Epoch0/能上传；实测 VRAM 定并行度（预计 1 并行）。
- P2.3 判定（§5.2）：两探针 vs P1.4 横杆。**阳性 → P3 扩展；阴性 → 记录 no-go（只否定行业图/截面注意力，不否定概念方向），Track B 止，资源回 Track A/A'。**
- 交付：双探针对照结论。产线门：backend/ddl/frontend = noop（仅新增模型与实验）。

### P3 — 条件触发的扩展（按 P1/P2 结果驱动，可并行）
- P3.a（若 P2 阳性）关系模型多种子（5）+ 滚动多窗 + 与腿 A/B 的预测正交性 → 判独立第 3 腿价值。
- P3.b（若 P1.3 阳性）**Track A' M2**：LLM 驱动分钟因子挖掘（复用 RD-Agent/CoSTEER，沙箱扩分钟聚合视图）。
- P3.c（独立判断）Track C：THS 概念成分采集 → 动态概念超图（HIST 概念版 / STHAN-SR）→ 相对行业图的再增量判定。
- 交付：扩展腿/因子的鲁棒评估。

### P4 — 成书上线（Track D）
- P4.1 书级门（§5.3）：与反转书正交核验、换手/容量/成本、风控三件套、体制门控设计。
- P4.2 组合层：趋势腿（A/B/±图腿）进 combine-backtest，与反转书统一在组合层评估；体制感知的两书资金分配。
- P4.3 治理与模拟盘：策略包治理 → 验证 → 选股 → paper-v2；**模拟盘穿越当前逆风体制 + 记录参与率分布**（扩容期权数据）。

## 8. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 单窗顺风体制偏差（最大风险，已属事实：测试窗为 924 往返上半场） | P0 真样本外（2026Q2 分化体制）+ 滚动多窗定案门 + 保守横杆 + 诚实预期（§1.2） |
| 选择偏差/多重比较 | 开发窗定性 + 新窗只验证不选择 + √(2·lnN) 折扣 |
| 涨停不可成交侵蚀趋势收益 | P0.2 量化统计（真实分钟涨停价）；纳入腿级门 |
| 截面批与 QE TSDatasetH 不兼容 | 方案 A 封装在自定义 model.py；先冒烟；VRAM 实测定并行度（预计 1 并行） |
| 行业图检验力不足 → 错杀概念方向 | §5.2.5 no-go 范围校准；MASTER 并行探针提供无邻接对照 |
| 特征太薄图模型「饿着」 | Alpha360 底料 + 私有因子 + M1 分钟因子（§6.2/6.3） |
| 邻接/成分未来函数 | 严格 PIT（in/out_date 边界）+ 反泄漏单测 + 版本化 artifact |
| 分钟回填算力/数据量 | 一次性批任务分担到远端 CPU；先典型 10 因子再扩展 |
| 尾部流动性（小盘集中持仓退出） | 书级风控三件套（§2.3）+ 跌停情景回测（真实涨跌停数据） |
| 概念数据采集与 PIT 治理成本 | 延后到 P3.c 条件触发；THS 主源口径已定 |
| 污染生产/主目录 | 全程隔离 worktree + docs/feature workflow；本设计 noop |
