## ⚠️ 识别的风险与缓解

### 🔴 Critical（必须修复）

**风险**: 交易日历计算不准确

**当前实现**:
```python
# 简化实现：1 自然日 ≈ 0.7 交易日
return start_date + timedelta(days=int(days / 0.7))
```

**修复方案**:
```python
# 查询真实交易日历
async def _get_nth_trading_day(self, start_date, n_days):
    query = """
    SELECT cal_date FROM market.trade_cal
    WHERE cal_date > %(start_date)s AND is_open = 1
    ORDER BY cal_date LIMIT 1 OFFSET %(offset)s
    """
    # 返回第 N 个交易日
```

**修复时机**: ⚠️ Day 3 实施期间（阻塞验收）

---

### 🟡 Medium（建议修复）

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| QE workspace 可用性依赖 | 阻塞研发流程 | ✅ 已有重试逻辑 + 本地缓存 |
