## 4. 唯一交互规格与构造关系

既有低活跃主效应 `A=-db_turnover_rate_f`，即ID1355 `m_free_turnover_rate` 的原定义；不覆盖或改写ID1355。状态输入 `M=close(T)/close(T-20)-1`，查完整交易日历，两个端点都须属于同一有效PIT span且价格有效；不对删除缺行后的股票序列shift，不前填或跨span。

在T日非S合资格、A和M均有限的截面C_t上，以average rank计算：

```text
qA = rank(A)/(n_t+1) - 0.5
qM = rank(M)/(n_t+1) - 0.5
F  = qA * qM
研究名称：research_low_activity_trend_interaction_20d
```

这是**对称交互表示**：相对低活跃/强势与相对高活跃/弱势两格均可能为正，另两格可能为负。不能把它叙述成只买低活跃赢家，不能把相对强势误称绝对上涨。预登记原信号方向为正，依据是“低活跃关系随相对趋势增强”；该叙事是待检验假设，四格及单独主效应会检查它是否实际上是另一机制。

缺少A或M输出NaN并保留理论分母；乘积真实为0可保留，不能把缺失变0。先在完整C_t算排名/乘积再分块存储，不能在小股票批次各自排名。输出float32、单列、唯一 `datetime/instrument` MultiIndex；原值/单位不因评价结果改变。

F是明确可得输入A/M的已知变换，**无新增来源信息，但不是完全重复输入**。低相关或高张成度不能决定使用价值。存量查重必须对照全部596项已审核代码快照中实际读取/运算，而不只看名称；其范围不是实时生产全库，缺失元数据显式unknown。优先核对ID442 `turnover_adjusted_momentum_10d` 与其他量价交互，不默认它们与F同构。

## 5. 对照与拟合：主效应不能被漏掉

主比较为B强与B强+F；补充比较为B基本与B基本+F，两边使用各自完全相同的训练行、拟合规则和评价行：

- B基本：A、M、1/5/10/60日收益、20日波动、log总市值、普通换手。M同时是20日收益主效应，不再加入另一同义列造成重复。
- B强：B基本加ID442的原始换手调整动量。该近邻按既有原公式计算/复用，完整独立评价缺项只补本对照需要的同版部分；没有可比历史时明确披露，不偷偷用弱基准替代后仍称B强。
- 自由换手与A为确定负号关系，不另列一个自由换手主效应。其他存量近邻只作全范围相关性诊断，不根据本轮评价结果临时进入B。

复用当前 `comparison.py` 的 `research_role=predictive_increment` 数值路径，candidate=F；A及M均作为不同名字的真实基准信号绑定，不用同值别名绕过参数限制。**不使用conditional分支再乘一次state**：当前该分支会另外构造排名候选×排名state，且candidate不能同名处于baseline；本轮已经显式构造F，不能双重交互或漏掉A主效应。

该数值路径会在模型共同输入截面再次rank每列（包括F），故比较对象是**rank(F)表示的增量**，不是直接对原乘积水平做因果系数估计。公式完整独立评价保留原F；两者各自的信号/截面必须标明，不拼接为同一统计结论。模型共同输入样本受60日热身/近邻缺失限制，不能用其分母代替原始PIT或F覆盖分母。两组各自保持B/B+F同样本；若B基本与B强的样本不同，不把两组差值相减后归因于近邻控制。

两边分别拟合带截距的横截面rank OLS、日期等权，无模型/参数/方向搜索。2018起的扩展拟合截至2023/2024/2025年末收盘，分别回放2024/2025/2026至cutoff；查共享 `HOLDING_PERIODS` 的2/6/11/21价格日期排除未成熟和跨评价边界训练标签。历史锁定是模拟而非当年真实预登记，所有已接触区间为 `research_feedback`；无须等待未来行情。

登记正向公式与自由拟合系数分开：若拟合使用反向关系或作用仅来自高活跃弱势格，不宣称原正向机制得到支持；可报告该固定使用规则的实际结果，不修改原公式方向追认成功。现有comparison返回拟合元数据但不含系数，不能假称其已输出方向证明；如确需保存系数，仅在X编排中复用同一 `_weighted_fit/_predict`，保存实际系数/列序并核对预测与主比较一致，不改共享接口或再搜索拟合规则。rank(F)系数也不是原始A×M的经济因果斜率；系数未取到则方向证据unknown。

## 6. 完整评价与判断口径

3. F×全部可评价参考、必要候选/对照对数；全历史与重点窗口的同日横截面Spearman、有效日期/股票数和不可用原因。使用596参考快照时明确其时点，已有不可用项不修复成成功；不重算旧×旧矩阵。
4. 两组B/B+F各四期限×三个回放年度，共24个年度比较窗；按日期配对ΔRankIC，及重点近期汇总。HAC带宽预设5/10/15/25，作为本轮选择而非期限定律，披露连续区段、有效日数与缺口，不把不连续日拼为连续样本。报告无多重性保证。
5. 四格补充诊断：qA正/负 × qM正/负，0或缺失单列；分别报告机会/成熟有效数及原F排序关系。格定义仅用T信息，不据未来收益选股；格内统计不是全股票Δ或可执行收益，不以小格较好掩盖全范围比较。
