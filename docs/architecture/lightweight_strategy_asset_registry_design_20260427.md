# 轻量策略资产管理与执行 Adapter 设计思路

日期：2026-04-27
状态：设计记录 / 当前阶段执行边界
适用范围：QE、RD-Agent、Paper Trading v2、未来模拟盘/实盘接入前的策略资产治理。

## 1. 核心结论

当前不应建设“所有策略组合都提前版本化”的重型资产系统。正确方向是：

```text
+------------------------------+--------------------------------------------------+
| 原则                         | 说明                                             |
+------------------------------+--------------------------------------------------+
| 统一登记                     | 所有策略、执行算法、模型快照都有 ID/hash/状态    |
| 独立版本                     | 日频策略、执行算法、HMM 快照分别版本化           |
| 运行时引用                   | 实验/回测/模拟盘只记录本次实际使用的资产引用     |
| 不做笛卡尔积                 | 不提前生成“日频策略 * 执行算法 * HMM”的组合包    |
| Adapter 不成为策略版本       | Adapter 只做环境接入，不能复制业务逻辑           |
| 历史可复现                   | 已运行实验 pin 到当时的资产 ID/hash              |
+------------------------------+--------------------------------------------------+
```

统一管理的含义是统一 registry、统一解析、统一校验；不是把所有资产打成一个超级版本包。

## 3. 资产分层

```text
+--------------------------+--------------------------+------------------------------+
| 资产                     | 主键                     | 被谁引用                     |
+--------------------------+--------------------------+------------------------------+
| 日频策略                 | strategy_id + version    | QE 实验 / StrategyPackage     |
| 执行算法 release         | algo_code + release_id   | QE 实验 / Paper policy        |
| 执行 Adapter             | 随执行算法 release 冻结  | QE / RD-Agent / Paper v2      |
| HMM 快照                 | model_snapshot_id        | runtime_profile              |
| 选股分数产物             | artifact_id              | Selection Center / Paper v2   |
| 实验/运行组合            | experiment_id / run_id   | 结果复现                     |
+--------------------------+--------------------------+------------------------------+
```

### 3.1 日频策略

日频策略只负责选股、排序、目标持仓或调仓意图，不拥有分钟线执行 Adapter。

应管理：

- `strategy_id`
- `source_code` 或 `source_code_relpath`
- `default_kwargs`
- `param_schema`
- `strategy_version`
- `source_sha256`

### 3.2 分钟线执行算法

执行算法 release 冻结 core 与 adapter：

```text
execution_algos/
  V25_TWO_STAGE/
    releases/
      2026-04-27_001/
        manifest.json
        core/
        adapters/
          qe_qlib_adapter.py
          rdagent_adapter.py
          paper_v2_adapter.py
```

用户选择的是 `algo_code + release_id`，不是单独选择 adapter 版本。

### 3.3 Adapter

Adapter 允许做：

- Qlib / Paper / RD-Agent 对象转换；
- 路径、参数、运行环境接线；
- 错误和 reason code 封装；
- 运行快照复制。

Adapter 禁止做：

- 自己实现一份执行计划；
- 自己决定尾盘补单规则；
- 自己决定零股/非整股卖出规则；
- 自己实现涨跌停/停牌业务语义；
- 缺模型或缺数据时 fallback 到 TWAP/收盘价/空成功。

### 3.4 HMM 快照

HMM 是模型快照资产，不应并入执行算法 release，也不应复制进每个日频策略版本。

```text
+--------------------------+----------------------+------------------------------+
| 资产                     | 管理方式             | 是否放入执行算法 release     |
+--------------------------+----------------------+------------------------------+
| V25 core 代码            | algo release         | 是                           |
| V25 QE adapter           | algo release         | 是                           |
| V25 Paper adapter        | algo release         | 是                           |
| 日频策略源码             | strategy catalog     | 否                           |
| HMM 训练配置             | model config         | 否                           |
| HMM 模型快照             | model snapshot       | 否                           |
| HMM coefficients         | snapshot artifact    | 否                           |
+--------------------------+----------------------+------------------------------+
```

## 4. 运行组合记录

实际一次实验只记录引用，不创建永久组合策略：

```json
{
  "experiment_id": "qe_xxx",
  "strategy": {
    "strategy_id": "score_weighted_topk_v2",
    "strategy_version": "2026-04-14",
    "source_sha256": "..."
  },
  "execution_algo": {
    "algo_code": "V25_TWO_STAGE",
    "release_id": "2026-04-27_001",
    "manifest_sha256": "..."
  },
  "hmm": {
    "enabled": true,
    "model_snapshot_id": "bbec3863-fb67-445f-938e-66f092d18696",
    "signal_preset": "preset_A",
    "coefficients_sha256": "..."
  }
}
```

不应创建这种永久策略名：

```text
score_weighted_topk_v2__V25_TWO_STAGE__QE__HMM_bbec3863
```

## 5. 版本与生命周期

```text
+--------------------------+--------------------------------------------------+
| 对象                     | 生命周期策略                                     |
+--------------------------+--------------------------------------------------+
| 当前开发源代码           | 只保留一个权威源头                               |
| active release           | 新实验默认使用                                   |
| 历史 release             | 保留，用于复现实验                               |
| workspace copy           | 运行快照，不是权威                               |
| HMM active snapshot      | 默认推荐使用                                     |
| HMM archived snapshot    | 默认隐藏，但可复现                               |
| pinned asset             | 被实验引用后禁止静默删除                         |
+--------------------------+--------------------------------------------------+
```

HMM 快照推荐状态：

```text
+------------------+--------------------------------------------------+
| 状态             | 说明                                             |
+------------------+--------------------------------------------------+
| active           | 当前默认推荐使用                                 |
| completed        | 训练完成，可用于实验                             |
| pinned           | 已被实验/运行引用，不能删除                      |
| archived         | 默认隐藏，只用于复现                             |
| failed           | 保留错误记录，不参与选择                         |
| superseded       | 被新快照替代，默认隐藏                           |
+------------------+--------------------------------------------------+
```

## 6. 当前阶段执行边界

本阶段只处理一个明确问题：

```text
+------------------------------+--------------------------------------------------+
| 项目                         | 本阶段处理方式                                   |
+------------------------------+--------------------------------------------------+
| QE V25 非整股/零股卖出尾仓   | 修复                                             |
| RD-Agent V25 模板             | 同步修复                                         |
| Paper v2 V25                  | 暂不修改                                         |
| V24                           | 暂不修改                                         |
| 数据库资产                    | 不修改                                           |
| 历史 QE workspace             | 不静默替换                                       |
| HMM 资产                      | 不修改                                           |
+------------------------------+--------------------------------------------------+
```

修复目标：

- V25 日内执行遇到小于交易单位的 SELL 剩余量时，直接一次性发出清仓卖出单，不再进入 V25 分配计划；
- 非整手、零股、非整数股的 SELL 尾仓可以在任意可交易分钟直接发出，不需要等到最后一分钟；
- 最后一步 SELL 仍保留不按 100 股交易单位重新取整的保护，避免尾部 rounding 再次产生残留；
- BUY 小于交易单位时直接跳过，不生成小额买入单，P0 分支也不得发出小于 100 股买单；
- 保持 Paper v2 V25 当前逻辑不变。

## 7. 后续推荐落地顺序

```text
+----------+------------------------------+------------------------------------------+
| 阶段     | 工作                         | 目标                                     |
+----------+------------------------------+------------------------------------------+
| 第一步   | 修复 QE/RD-Agent V25 尾仓卖出 | 先解决持仓暴涨的直接执行层问题           |
| 第二步   | 建立执行算法权威目录         | 解决 V24/V25 多处代码不一致              |
| 第三步   | release manifest + sha256     | 运行前校验文件未漂移                     |
| 第四步   | 运行组合引用记录             | QE/Paper/Selection 可复现                 |
| 第五步   | active/archived 生命周期      | 控制 UI 资产列表复杂度                   |
+----------+------------------------------+------------------------------------------+
```

## 8. 禁止事项

```text
+------------------------------+--------------------------------------------------+
| 禁止事项                     | 原因                                             |
+------------------------------+--------------------------------------------------+
| 为每个日频策略复制 Adapter   | 会导致大量重复代码和漏改                         |
| 提前生成所有组合资产         | 会形成笛卡尔积爆炸                               |
| HMM 快照嵌入策略源码         | 模型快照与策略源码生命周期不同                   |
| 用户手动选择 Adapter 版本    | 容易造成 QE/Paper/RD-Agent 语义漂移              |
| 静默替换历史 workspace 文件  | 会破坏旧实验复现                                 |
| V25 静默 fallback 到 TWAP     | UI 配置与真实执行不一致                          |
+------------------------------+--------------------------------------------------+
```
