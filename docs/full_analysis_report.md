## 结论

### h5 缺失日期的 bin 数据

- 2010-06-14: bin 文件无数据
- 2010-06-15: bin 文件无数据

### 记录数差异分析

- bin 文件总记录数是 h5 的 1.67 倍
- h5 每只股票的平均记录数: 2317.91
- bin 每只股票的平均记录数: 3861.00

差异原因:
- bin 文件使用 dump_bin.py 的 data_merge_calendar() 方法进行日期对齐
- 如果股票在某交易日没有数据，填充 NaN
- h5 文件只包含有数据的日期，不包含无数据的日期
- 因此 bin 文件的总记录数会更多（包含所有交易日，即使数据为 NaN）
